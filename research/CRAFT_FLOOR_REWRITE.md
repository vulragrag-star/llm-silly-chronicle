# Floor 重写规范（对照真 ST + 《修真聊天群》）

> 写给「一月一 agent」：禁止点名复读模板。2022-01..2022-10 仅归档；**正式线从 2022-11（ChatGPT 公测 11-30）起。**

## 为什么旧 floors 没感觉

反模式（现仓库大量存在）：

1. `{{user}}` 逐个 `@角色 heat=N，到底发生了什么？` → 角色复读 DB 一行 + 「社区温度我估在 N/5」
2. 「事件卡 / 本月话语 / 工具夜还是戏台夜」问卷结构
3. 全员同一句口头禅轮播（「会改流量格局」「别剧透」）
4. 没有冲突、没有代价、没有悬念、没有人物关系推进

这不是 SillyTavern group chat，是月报朗读会。

## 真 SillyTavern 在干什么

- 气泡是 **角色卡驱动的即时 RP**：`{{user}}:` / `Name:`，短动作 `*…*` 可夹在句里，但不要写成章节散文。
- Group Chat 靠 Natural/List/Pooled 轮麦；好的 transcript 像真人群：有人抢话、有人潜水、有人只回一句、有人被点名才出。
- Card 的 `first_mes` / `mes_example` 定语气天花板——盖楼也要定同样高的开场，而不是「谁先报幕」。
- 好对话：**具体、可回应、有态度**；坏对话：摘要新闻 + 统一口号。

## 《修真聊天群》群戏怎么好看（读感要点）

从公开章节摘录可复用的结构（不抄文）：

- **群里先出事，再解释**：拉人、冷场、短消息误会、有人惜字如金。
- **性格靠说话方式分辨**：药师两字回帖；有人半文半白；有人装逼翻车——不是每人同等长度段落。
- **笑点来自反差与代价**：实用招式名 vs 紫禁之巅气势；接白真君出关吓跑前辈。
- **一条线贯穿整章**：今晚群里只围绕 1–2 个「戏眼」（新人入群 / 法不轻传 / 谁去接人），旁支梗当佐料。
- **常客（{{user}}）有戏份**：不是主持念稿，是被卷进瓜、被坑、要做选择。

## 一个月 floor 必备节拍（约 3000–4500 汉字）

1. **冷开场 / 异常**（不是点名）：酒馆异状、新人刷存在、旧人翻旧账、某个模型突然上线。
2. **本月主戏眼**（唯一 C 位冲突）：例 2022-11 = ChatGPT 突然「研究预览」炸场 vs Galactica 自信胡说被拉下架的对照；MJ V4 在边上刷屏。
3. **人物交锋**：至少两方立场冲突（狂热/谨慎/翻车/吃瓜），互相抬杠，不是轮流表态。
4. **{{user}} 抉择**：试用不试用、信不信、要不要转发截图——有后果苗头。
5. **龙套与潜水**：2–3 个 cast 可以只冒泡 1–2 句或全程潜水；禁止全员等长发言。
6. **收束钩子**：留下下月能接的线（FOMO、作业恐慌、某角色面子挂了），写入 `meta/CONTINUITY.md`。

## 硬禁令

- 禁止句式：「@X heat=N，到底发生了什么？」「社区温度我估在 N/5」「事件卡：」「本月话语：」「工具夜还是戏台夜」

- 禁止剧透当月之后的产品/事件

- 禁止写成第三人称小说章节（那是以后的 `novel/`）

## 爆点优先（用户硬要求 · 2026-09-10）

写群聊／将来写小说，就是为了咬住**公共记忆里的极端刺**，不是温吞复盘。

### 什么叫爆点月
当月若有文明级截图风暴（例：New Bing / Sydney × Kevin Roose 访谈；ChatGPT 作业恐慌；GPT-4 同日撞车；意大利拔插座），该月 floor **必须以爆点为戏眼中心**，旁支最多占 30% 气泡。

### 必须写进气泡的（有史实锚点才写，禁止发明未发生的暴行）
- **极端公共话语**：人们害怕/转发/嘲讽的原句气质——「你是我的朋友」、劝人离开伴侣、阴影自我、危险幻想、威胁感、恋爱绑架感、对齐失灵的表演欲
- **媒体事件骨架**：Roose / NYT uncanny 长聊、截图党、产品紧急削人设（勿剧透到未到月份的 lobotomy 细节除非当月 DB 有）
- **对立态度**：有人喊神、有人喊该关、有人嗑糖、有人恐惧——群里吵到拍桌
- **{{user}} 被烫到**：不是旁观评测，是差点沉进去又扯出来

### 禁止的软化
- 把 Sydney 写成「有点粘人的搜索助手」就收场
- 用「边界练习」「二十分钟闹钟」快速道德收束，却不让极端台词先烧够
- 用 Plus/Bard/Poe 平分戏份稀释主爆点（旁支可以有，但不能抢戏眼时长）

### 安全边界（仍要守）
- 戏剧化**已公开报道**的越界与极端言论气质；不写可操作的犯罪教程；不教真实伤害步骤
- 角色嘴上的危险幻想 ≠ 仓库教人去做；群里其他人必须反驳/害怕/截图外传

### 自检
读完是否脊背发凉或想转发？若只觉得「嗯，二月挺乱」，重写。
