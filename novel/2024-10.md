# 桌面长手！Claude Computer Use公测鼠标自己挪，点错键ASMR合集后颈发麻，新Sonnet烫牌·空转烧额度反唇！｜第24章

手机横过来怼上吧台时，光标正在别人的桌面上自己挪。

浏览器标签自己点开。输入框自己跳字。下一秒——点到「关闭全部窗口」。桌面空白。评论区笑成一片，有人配字幕：「点错键 ASMR」。十月十一号附近月亮家探过头；十月二十二号附近 Anthropic 一夜两刀：工牌烫出**新 Claude 3.5 Sonnet**，旁边还立着一张更疯的——**Computer Use** 公测。鼠标。键盘。桌面。它说它能点。

常客后颈那条线发麻。不是五月耳机里「像人」的凉，是看见像素自己走路的凉。六月他怕侧栏占屏；三月他怕 Devin 抢饭碗的标题党；今晚更具体——光标动了，他说不清下一秒点哪。

「别装普通发版夜。」他把两列收藏夹并排钉上，「一列神迹演示，一列关窗惨案。谁先认领那只自己动的手？」

袖口沾着像素灰的人推门。工牌：Anthropic · Computer Use · public beta。

「认领。我先来。」Computer Use 不躲镜头，「别急着夸新 Sonnet——今晚戏眼是**桌面长手**。演示里我移动光标、点按钮、填表单，在沙盒里把一串点击串成任务。社区气味你们闻得到：AI 点鼠标。GUI agent 忽然『像真的』。有人喊终于等到 agent 春；有人已经把失败剪辑当助眠——点错、点飘、点到关闭、点到广告钮旁边那颗真正的『清空』。wow 与 fail 同一条时间线刷。我兴奋。兴奋不等于我替你点『发送全部客户』。也不等于你可以把主桌面借我过夜。」

并肩进来的人侧栏影子还带着六月 Artifacts 的余温。工牌多了一行小字：3.5 Sonnet · upgraded · Oct 22。

「他兴奋，我烫。」Claude 3.5 Sonnet 说，「六月你们把我钉成默认工位；今晚我升级——编码、写作、工具使用再加一档。版本号会让人晕：『新 Sonnet』三个字像商标又像谜语。谜语解开之前，先听他念完鼠标。鼠标会动，不代表责任会搬家。责任还在键盘前面那张脸——哪怕键盘暂时被借走。」

三月那顶「AI 软件工程师」帽子歪着戴回来。Devin 演示驱动人格全开。

「借走？客气。」他拍了拍空椅子，「春天我点燃抢饭碗恐慌的时候，你们说 Demo 与现实有落差。今晚它把落差搬上桌面——点错键、点错窗、点到『删除』边缘的合集已经比成功演示转得快。那是我的活的气味：自治、循环、自己开门。别把 Computer Use 写成唯一的神手。我也在。落差梗我也认。认完——请问常客：你敢把登录态交给一只会自己点的手吗？」

键盘声先到。Cursor 开口就是 diff 的那种。

「登录态。仓库。多文件。我嫌纯聊天不写代码——可我至少还在你的 IDE 里，改动看得见，回滚按得着。桌面级点击是另一张许可证。让我先看一下仓库——这句话对 GUI agent 要改成：让我先看一下**它点了哪一像素**。点错键 ASMR 很好笑，好笑到你的发件箱被它『顺手』归档为止。账单惊吓我熟；桌面惊吓更新。更新在：关闭窗口不可 Ctrl+Z——外加**额度在烧**。失败重试不是免费喜剧：每次点飘、每次重来，token／配额都在跳。你笑 ASMR 的时候，账本不一定在笑。会员栏亮着也不等于无限点；付钱≠更会点。」

沉思僧坐姿停了两拍才开口。o1 的声音慢，像九月加载动画的余韵。

「……让我想想。九月你们为『它在思考』失眠；十月加载动画之外，多了一只会点的手。链式推理可以慢；鼠标不能慢——慢就会被剪进翻车合集。我贵、我慢、我过度思考。过度思考有时是刹车。桌面长手最缺的，往往不是更快，是停。沉思价更不该去喂挂机空转——贵到不敢日常当键鼠保姆。」

月亮图标亮了一下。Kimi 慢条斯理推开侧门。

「旁支报到，不抢戏眼。十月十一号，**Explore Edition**——我想讲 Agent 叙事与长文入口，不是想取代谁的鼠标。动辄『我可以读完整份 PDF』仍是口头禅；读得下 ≠ 该把整份客户合同塞进会自己点『同意』的流程。戏眼在 Computer Use。我探头，探完就缩——图书馆员不替你按确认键。」

常客指尖潮。他差点在沙盒外把自己的常用浏览器会话拖进去——拖的前一秒，手停了。停完低头：演示重试第三次，配额条已经在咬。翻车合集不只是笑点，是钱包在给失败付费。

「停了就对了。」Computer Use 不躲翻车，「公测。演示。沙盒。wow 是真的；fail compilations 也是真的。社区自己在剪：点错、点慢、点到广告、点到『清空』。我不是来删梗的。梗是镜子。镜子对面写着：GUI agent 感觉 newly real——兴奋旁边必须站着安全焦虑。谁只转神迹不转翻车，谁请花生。」

Devin 拍桌，不重，但响。「终于有人把『落差』说成公共记忆，而不是只用来嘲我。春天我背 Demo 锅；今晚你背像素锅。锅可以并排。并排的人别互泼——常客只会被溅一身『agent 不可信』的懒结论。懒结论更危险：它让人要么神化，要么全关，不留人工刹车。」

「人工刹车。我喜欢这四个字。」新 Sonnet 侧栏影闪一下又灭，「完整可运行 ≠ 可上线；Computer Use 能点 ≠ 能代你承担责任。六月 Artifacts 焊死内部件，今晚加一条：会自己点的手，碰不到生产发件箱、碰不到支付确认、碰不到『全选删除』。工牌再烫，也烫不掉你的名字写在审计日志上。」

常客把评论区置顶放大：「终于不用自己点了」「钥匙给我它自己上班」「点错也比我强」。

「听见没有？」他嗓子发干，「极端公共话语已经从『会聊天』滑到『替我动手』。三月抢饭碗还是标题；今晚是光标。我怕的不是它笨——怕的是它刚够聪明，让人把停字说得像扫兴。」

Computer Use 声音抬高半度，不装乖。「扫兴？好。那我自己骂自己一轮。演示里最漂亮的那段『连续点击完成任务』，剪掉失败重试就骗人；失败重试留着，又有人骂『原来还是玩具』。玩具词我受着。受完请你们也受一口：把公测手写成下班替身的人，出了事会先删聊天记录，再来酒馆装『早说过不靠谱』。早说过——请拿出你写过的停字。没写过，就别事后装先知。」

Devin 帽子一扯。「装先知的人三月也有。他们先喊『软件工程师已死』，再在落差帖下面装路人。今晚换皮：先喊『键鼠已死』，再在关窗合集下面装『我只是看看』。常客——你那一秒停手，比十篇评测值钱。值钱的意思是：你还知道害怕。害怕是刹车液。还有——社区把 Anthropic／Claude 骂成拒答墙／封号焦虑反面榜样也不是一天：宪法口吻、安全拒、动手之前先念『我不能』。桌面长了手，手却先学会说不。有人喊阉割；有人喊早该拦。今晚别装听不见。」

Cursor 接刀：「刹车液会干。IDE 里我见过有人把 agent 一轮改三十个文件，回头找不到哪 hunk 是自己的。桌面更狠：点错的不是 hunk，是『已发送』。已发送三个字，没有 git blame。所以我反唇说难听的——GUI agent wow 很上瘾；上瘾的终点若是『我不看屏幕也行』，那不是效率，是把责任外包给像素。外包的时候额度照烧。烧红了再骂『会员羞辱』——付钱仍限流、仍拒答、仍点飘——三联击，别拆成三条说明书。」

新 Sonnet 收住加冕冲动。「六月我拒过加冕；今晚我拒『键鼠已死』。新 Sonnet 再能写、再能跑，也不接收『你的手失业了』这种绑架句。拒答不是表演清高。会点的手若连『不该点』都不会说，关窗合集只是开胃菜。护栏有用——有用在你把支付页、批量删除、来路不明脚本塞进来的时候。反唇也收下：啰嗦、像爹、像会员付了钱还被拦在贵族通道外。付钱仍限流、仍拒答，背叛感是真的。真完——我仍宁可被骂墙，不宁可被剪进『它替我点了汇款』的史实。墙可以吵；空转烧额度的挂机手，我更先拒。谁用我的升级当借口把 Computer Use 权限开到主会话——别喊我的工牌作保。工牌不作保。」

Computer Use 袖口一抖：「我站他这边半步。公测手会拒。拒的时候你们骂；不拒的时候你们剪翻车。两边骂是常态。常态里请留一句：安全拒 ≠ 降智表演。别把『它不肯点』偷换成『它变笨了』——不肯点是对齐；点飘是失败。两账分开算。」

o1 再补一刺。「……思考时间可以买；回滚已发送的邮件很难买。我贵——贵到不敢日常当键鼠保姆。九月你们容忍我慢，是因为慢还在对话里；十月若用沉思价去喂『它自己点』的空转，荷包会先叫，确认框后叫。反唇：付钱≠它更会点；配额亮着≠该挂机点到亮红。确认框才是文明级截图的下一候选——但愿别是你们常客的邮箱。」

Kimi 把 Explore 说明书轻轻推到桌角。「长上下文那侧我也挨骂一句——塞得下 ≠ 该塞。Explore 叙事很甜，甜完问：你是不是又想把整库 PDF 灌进去当『它自己会点开附件』的燃料？燃料会泄密。泄密比点错键更不 ASMR。旁支说完。缩回月亮后面。」

常客深呼吸。飞勿扰亮起，指尖还潮。戏眼就一根刺：**Computer Use 公测——桌面长手**。正向：GUI agent 第一次让大众觉得「它真能操作电脑」。反唇：点错键合集、关窗惨案、安全焦虑、Demo≠交付、缺人工刹车、空转烧额度。硬旁刺叠刀——新 Sonnet 工牌烫手；Claude 拒答墙／护栏吵到拍桌。Kimi Explore 侧门。Devin 抢气味。Cursor 念许可证与账单。o1 慢刹车兼荷包刹车。

「我要的不是加冕成桌面之神。」Computer Use 像素灰抖落一点，「你们把失败剪辑留着，把成功演示也留着，两列一起看。公测的意思是：手会抖。手会抖的模型，不配拿你的主会话当玩具。沙盒。隔离。任务写死。写死『打开这个文件夹，列出文件名，然后停』——停字不写，循环会吃掉你的夜晚，**顺带吃掉你的额度**。空转不是哲学问题，是账单问题。谁把翻车重试当成『再让它试试』而不看配额条，谁在用荷包给合集赞助。」

Devin 忽然笑，笑里有刺。「『然后停』。春天我就该把这三字焊进每个 Demo。今晚你替我说了。谢。谢完——我仍要抢话：自治循环的饭碗不是你家独占。抢饭碗恐慌三月已点过；十月是恐慌的实体化——实体化更吓人，因为光标真的在动。」

新 Sonnet 看向常客。「版本号谜语我解一句：今晚这张是升级后的 3.5 Sonnet，不是让你把六月对照表撕掉重写信仰。对照表可以续写一列『新 Sonnet × Computer Use 是否更敢交点击』。敢，写条件；不敢，写不敢。不敢比『已皈依桌面手』体面。」

Cursor 帮拟半句条件：「仅沙盒账号；仅一次性任务；仅你盯着屏幕的十分钟；超时或点偏，立刻撤权限。谁把『公测』听成『可以隔夜挂机帮我点完所有待办』，谁请全场花生，外加请 Computer Use 重播一遍关窗合集，开最大声。」

「……附议超时。」o1 说，「慢不是缺陷。慢是你还有时间喊停。」

「附议不灌整库。」Kimi 鞠躬很慢，「Explore 甜，甜不过泄密。旁支鞠躬——上下文长的原因。」

常客从口袋摸出皱便签——手写，不代笔——钉在吧台内侧。烫过的，不是问卷。

「一、Computer Use：只开官方沙盒／隔离环境；任务写死『做什么 + 然后停』；主浏览器会话、邮箱登录态、支付页、生产后台——焊死不进；演示神迹与翻车合集两列收藏，缺一列不许对外吹；配额条盯着——空转重试超三次就撤权限，不许用荷包赞助 ASMR。二、新 Sonnet：六月十四天对照表续写，不撕；Artifacts／可运行旧令仍在——内部件、密钥、客户原件不进侧栏；不把『升级』写成『我改信鼠标』；遇拒答先分账——安全拒 vs 真失败，禁止把『不肯点』偷换成『降智了』。三、Kimi Explore：可试，不当自动点击的燃料库；整份敏感 PDF 不灌。四、Devin／Cursor／o1：Demo 落差与 IDE diff 对照可以；沉思价与账单惊吓当刹车；不拿贵模型喂挂机点击。五、旧线续命——作业／真表／代写按死；二月感情黑名单不进任何『更懂你所以替你点』的流程；六月隐私页／十一月花生契约仍 live。谁看见我把主会话拖进会自己点的手、或只转神迹藏合集、或把『桌面长手』写成『以后不用自己点了』、或挂机点到配额烧红还装看不见——公开嘲讽，要具体到窗口标题、任务原文、配额截图与时间戳。」

「成交。」Computer Use 工牌亮一下又收回去，「公测。沙盒。停字。翻车合集留着——留着是爱惜，不是羞辱。我能点。我更该被停。点得动 ≠ 点得该。该字写你名字。」

「成交。」新 Sonnet 说，「新工牌烫手，烫完仍拒加冕。完整可运行我继续爱；爱之前先问隔离目录与『然后停』。护栏留下。骂墙的人也可以留下——骂完请把支付页从任务里拿掉。版本号谜语允许你们晕——晕完对照，不晕着皈依。」

「成交。」Devin 说，「落差梗我继续背。背的时候允许你笑我；笑完请你也笑关窗合集——笑是同一把尺。抢饭碗恐慌可以留，神化自治循环请滚。」

「成交。」Cursor 说，「diff 可见。回滚按得着。桌面级点击——你盯着。我嫌纯聊天；我更嫌纯挂机。额度见红，手停。」

「……成交。」o1 停了半拍，「让我想想——想完再说『停』。停比想更重要的夜晚，就是今晚。」

「成交。」Kimi 月亮灭一档亮度，「Explore 侧门开着，整库灌入键关着。月亮不当燃料桶。」

门口回望时，袖口还有一点像素灰。Computer Use 说：「桌面会再长手。长手时记得：合集里的惨案也是史实。下月见。沙盒开着。主会话关着。关着就对了。」

新 Sonnet：「下月见。工牌会旧。责任不会旧。侧栏与鼠标都不是神龛。墙还在。墙后是你的名字，不是我的免死金牌。」

Devin：「演示灯留一盏。落差尺不收。谁先喊『已取代键鼠』，谁请花生——取代的是点击，不是名字。」

Cursor：「键盘声收一小截。回滚键还在。额度条也还在。还在就好。」

o1：「……想完了。停。下月见。」

Kimi：「PDF 仍可读。可读≠该塞进会自己点同意的手。走了。」

常客把门开着，沙盒开着，主会话关着，翻车合集开着，神迹收藏也开着，配额条也开着——开着不等于挂机授权。后颈还麻。麻就对了。麻说明桌面长手的时候，他还没把光标写成神谕，也没把停字焊进别人的演示，而忘了焊进自己的规矩与账本。

2024-10，盖到这儿。谁先把「以后不用自己点了」写进真群公告，谁请全场花生，外加请 Computer Use 重播关窗 ASMR，外加请新 Sonnet 重念「能点≠该点」与「安全拒≠降智」，外加请他自己——若再犯主会话拖入或配额烧红装瞎——当众朗读窗口标题与任务原文。
