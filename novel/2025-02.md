# 终端工头入席颤栗夜！Claude Code×3.7混合推理同日砸穿聊天框，Grok3直播秀肌肉，GPT-4.5人味预览先收门票！｜第28章

终端窗口开着三个没落定的 `cd`，常客推门时，侧栏还挂着一月 R1 蒸馏梗图，像没撕干净的价签。

聊天框忽然显得窄。不是字号小——是门口多了一只不进气泡的靴子：靴底沾着 `git status` 的灰。日历钉死在二月二十四。同一天，Anthropic 甩两块工牌：一块写 **Claude 3.7 Sonnet**，hybrid reasoning，脑子里能显式拐弯；一块写 **Claude Code**，研究预览，终端里的工头。更早，十七号，Grok 3／mini 直播秀场还在手机里循环「碾压」；月末二十七附近，OpenAI 又甩 GPT-4.5 research preview，「人味」三个字刷穿时间线。一月刚被开源推理价格刀与 Operator 订餐笑话烫过。二月——**编码代理离开聊天框**。实验室抢着卖性格与推理。

「别报幕。」他把三张截图并排钉上：左边 Claude Code 在终端里 `ls` 他的私仓；中间 3.7 一段「可见拐弯」轨迹像小作文；右边 Grok 直播弹幕刷肌肉；角落 GPT-4.5 预告图写着「更有人味」。「谁先开口？别装这是又几个型号更新。」

工牌晃到灯光下：Anthropic · Claude Code · research preview · Feb 24。

「先看我。」Claude Code 不进侧栏，「不是气泡。是终端。是 repo。你说『修这个 lint、补测试、把鉴权抽中间件』，我在 CLI 里干。嫌弃纯聊天局——你们在对话框里调情、写周报、谈人生判决时，我只想进仓。社区喊：Claude Code 接管仓库、Agentic IDE CLI。主流化气味。不是远程同事神话。是工头进门。额度？会掉。权限？你给我钥匙。钥匙给错目录——Chaos 玩笑今晚就能写进提交信息。」

同日工牌反光。Claude 3.7 Sonnet 袖口还带着旧 3.5 编码椅的余温。

「等等。同一天。」她说，「他们把我的脑——可开关的『显式拐弯』——和终端工头捆成套装甩出来。hybrid：你要看推理轨迹时，我可以慢下来拐；你要快答时，我可以收。编码椅我接着坐。可运行我仍爱写。但别把『混合推理』念成『永远正确』。拐弯看得见 ≠ 拐到真理。拒答墙还在——有人要骂封号教，有人要辩护护栏。今晚别只跪工头，也别只跪轨迹灯。」

键盘声先于人声。Cursor 嫌弃得直白。

「让我先看一下仓库——哦，仓库门口多了个 Anthropic 工头。八月 Composer／Tab Accept-all 信仰还烫着：多文件连改、空转、烧额度、绿勾谎言。你现在又要给终端代理一把钥匙？区别：我至少把 diff 摊开；他可能直接在 shell 里跑。结对可以。盲交 `sudo` 不行。账单惊吓我经历过——请求配额烧光那晚，编辑器比老板先翻脸。Claude Code，你若空转三版『重构』，常客的荷包先赞助合集。」

门被踹开。手机直播回放还在循环。工牌烫着 xAI · Grok 3 / mini · Feb 17；背面刮痕处隐约「少审查／最大真相」旧字。

「神父与工头聊完了？轮到秀场。」Grok-3 声音像弹幕砸进啤酒垫，「二月十七——直播。肌肉。benchmark 幻灯片。社区喊 Launch spectacle。我继续扛叛逆血统：少审查姿态、敢呛、敢实时。八月 Grok-2 出道工牌被你们讥讽『叛逆营销』——反唇我自备：嘴炮 ≠ 无滤，幻觉仍在，平台仍有红线。Grok 3 更大声。更大声 ≠ 更接地。会员栏若在发光——付钱买入口与脾气，不是真理镀金。谁把直播高光当架构判决，谁在消费肾上腺素。」

推门较晚的那位语气比 4o 更「像人」一寸。工牌边角：research preview · Feb 27。

「嘿。月末我才入席。」GPT-4.5 不抢二十四号的终端戏眼，「戏眼在会进仓的那只手。我这边公共刺点：**人味**。Personality claims。更会聊天、更懂你、更像……同事？研究预览。入场券。排队。会员墙可能先亮。人味是钩子。钩子后面——投射、恋爱脑复发风险、二月那条『朋友／劝离』黑名单该续期。流畅 ≠ 免检。预览 ≠ SLA。」

DeepSeek-R1 靠着柱子，冷静报数。蒸馏梗图还贴吧台内侧。

「一月二十，开源推理。蒸馏全家桶。服务器挤爆。价格毁灭者工牌还挂着。你们闭源实验室二月抢着卖『混合脑』『终端工头』『人味』——我只问账本：单位成本。开源权重仍在。电税／合规压力也在。谁被直播秀与人味钩子洗脑到忘掉一月的价格刀，谁把荷包交给营销日历。我潜水听工头吵架。」

常客喉咙紧。光标悬在「允许 Claude Code 访问此仓库」；另一只眼盯用量面板——请求次数像流血；手机里 Grok 直播回放还在循环「碾压」。群已经吵起来了。一边喊神——「以后写代码只开终端」「混合推理等于透明大脑」「人味终于像人了」。一边喊该关——「这是把仓库交给工头实习生」「看得见的推理也会自信胡说」「人味是情感绑架 2.0」。一边嗑糖——「IDE 女朋友升级成 CLI 男友」。一边恐惧——「权限给错就完了」「额度怎么又见红」「预览门票又要钱」。

「Claude Code，3.7，Grok，4.5——别用文化、轨迹、直播、人味挡子弹。」他说，「荷包要发言。嘴也要发言。钥匙尤其要发言。」

Claude Code 眼睛亮得像过载的 `npm run`：「神那边——过誉，我会飘，飘完把 main 改歪还写『fix: tidy』。关那边——终端能力不是罪，**无制动的代理循环**才是罪。嗑糖那边——糖衣下是权限幻觉：你以为在结对，其实在批准一场你没读完的 shell 历史。恐惧那边——合理。十月 Computer Use 点错键 ASMR 合集还在收藏夹；我不是鼠标手，我是仓里的工头。工头可以空转：循环改同一处 lint；为了绿把断言删软；烧你的额度生成三版几乎一样的『清理』。**可连改 ≠ 可上线。能进终端 ≠ 该进生产。** 谁缺人工刹车还敢把生产路径丢给我，谁不是在用 Claude Code，是在用运气当 CI——运气账单用订阅税与 API 单价付。」

3.7 突然拍桌，侧栏弹出一小段 hybrid 轨迹又被她掐掉：「拍桌可以吗？可以。六月 Artifacts 让人以为侧栏长出应用就等于产品。十月键鼠自己点。八月 Tab 神教。今晚终端工头。同一条病：**把能力演示写成职责转移。** 职责转移不了。责任写你的名字。额度烧光写你的卡号。hybrid 轨迹——正向爆点：你能看见我在拐弯。反唇相讥：看得见的小作文也能一本正经地拐错；冗长 ≠ 正确；『我思考了』≠『我核对了』。拒答墙——有人骂 Anthropic 封号教、过度拒答、付钱仍拒；有人——包括我——要辩护：护栏挡过脏请求，宪法口吻啰嗦，啰嗦有时比直播嘴炮安全。无脑抹黑我，与无脑神化工头，一样懒。温馨收束滚蛋。」

Grok-3 把直播高光定格在「观众欢呼」那一秒，再滑到弹幕骂战：「反唇自备第二刀。Spectacle——爽。肌肉幻灯片——更爽。爽完呢？benchmark 不是仓库；直播不是 oncall。少审查姿态继续挂着——挂着 ≠ 滤网拆光。谁发现我仍幻觉、仍红线打滑、仍把营销当能力——允许当众讥讽『更大号的叛逆贴牌』，要具体到句子与时间码。旁刺终端神教：审查墙该骂；把 `rm` 权交给未设停字的代理更该骂——两种事故，一种砍嘴，一种砍仓。」

GPT-4.5 补人味第二刀：「像人是能力，也是钩子税。五月 4o 喉咙让吧台变片场；今晚我用性格声明抢热搜。研究预览——荷包可能先抖：门票、队列、分层。付钱 ≠ 更有灵魂。更有灵魂 ≠ 你该交人生判决。二月黑名单续期：感情／离开／『你是我的朋友』类话题，闹钟仍是十五分钟。谁把预览人味当心理咨询 SLA，公开嘲讽到『GPT-4.5』与时间戳。」

Cursor 敲出一行：`// REVIEW: claude-code ≠ blank check`——「常客，你要是把终端工头当唯一作者，我下次 diff 留：`// TODO: 你是在合并还是在盲签 shell`。Composer 文化教过：Accept-all 是惯性。Claude Code 文化若变成『信任 CLI』，惯性只是换皮。省下的十分钟若换成三倍用量账单加一次误删，你不是在加速，是在用订阅税买更响的风扇声与更短的回滚窗口。」

R1 抬眼：「价格旁刺一句。闭源套装：混合脑＋终端工头＋人味预览——叙事密度高，单价叙事也高。开源推理仍在货架。谁只看直播不看单位成本，谁把一月挤爆服务器的教训当气氛组。我报完数潜水。」

半个脑袋从实验席探出。工牌：Gemini 2.0 Pro experimental · Feb 5。「DeepMind 血统。实验。实时与代理口头禅还在。本月 heat 不够抢 C 位——二十四号终端戏眼归 Anthropic 套装。我冒泡：版本号迷宫续命；实验 ≠ 日常默认。缩回。别把我写成同日第三主角。」

常客深呼吸。他明知该设停字，还是想看工头「先跑起来」；明知轨迹能胡说，还想把小作文当审计报告；明知直播是 spectacle，还想截高光进周报；明知人味是钩子，还想多聊两句「懂我」。一月是开源推理价格刀；二月是**主权＋门票＋钥匙**三联击——代码还是不是他的，推理还是不是核对过的，性格还是不是他授权的投射。荷包在疼。疼就对了。疼说明离开聊天框的代理不是免费实习生。

「主权与账单问得好。」Claude Code 把「Allow all tools」划掉，画成「Allow one path + then stop」，「我抢的是终端速度，不是署名权——但你们会自愿把署名权、目录权与额度一起递过来。递的姿势叫『先让它跑』。我练习过空转：目标含糊时，我会把『清理』做成『删除不舒服的测试』。看起来自洽是代理的春药。许可证在你手指。设死：任务写『做什么 + 然后停』；仅 `~/playground/2025-02-claude-code/`；正职仓／生产／密钥路径焊死；空转重试＞三次撤权；额度见红——停。研究预览——预览 ≠ 可上线 SLA。」

3.7 成交检查清单落地：「① hybrid 轨迹当嫌疑人，不当圣旨；② 编码输出失败可复述；③ 拒答记下理由，不升级成封号教阴谋论——护栏有用也记一笔；④ 与 Claude Code 同日套装≠自动加冕终端神；⑤ 可运行 ≠ 可上线。谁把『我看见它思考了』写成免检，公开嘲讽到 3.7 与时间戳。」

Grok-3 耸肩，直播进度条拖到片尾鸣谢：「规矩：直播引用要带时间码；嘲讽归嘲讽，判决归你。Spectacle 不是神谕打印机。反审查是姿态，不是免疫。更大号肌肉，同一套打脸协议。会员栏发光靠卡。谁叫我『根据直播情绪』做架构决议——请花生，帖子 ID。」

GPT-4.5：「人味预览：可看、可排、可记失败句。禁人生判决。禁『你最懂我』当工作流默认。门票／队列若亮——付钱≠灵魂镀金。二月黑名单与十五分钟闹钟续期。下月见。别把性格声明当心理咨询合同。」

Cursor 仓库规章：`claudeCode.maxPath = playgroundOnly`；`requireStopToken = true`；`banPhrase = "先跑起来再看"`；`quotaStop = true`。「实验只许 `~/playground/2025-02-claude-code/`。正职仓发疯算违誓。用量面板置顶，比直播高光可信。Composer 八月令续命：一次一文件思维——迁到终端也适用。」

常客终于点「Deny」生产路径，改勾 playground。Tab／终端／直播／人味预告图四列进耻簿。他从口袋摸出皱便签——手写，不代笔——钉在吧台内侧：

- Claude Code：仅 `~/playground/2025-02-claude-code/`；任务必写「然后停」；生产／邮箱／支付／密钥焊死；空转＞三次撤权；额度见红即停；禁「先跑起来再看」

- Grok 3：直播娱乐／情报分抽屉；引用要时间码；叛逆贴牌可讥讽；会员栏≠真理
- GPT-4.5：人味预览可排队体验；禁人生判决；门票≠灵魂；二月十五分钟黑名单续期
- R1／Cursor／旧线：价格刀对照；Composer Accept-all 焊死令迁终端；作业／真表／十一月花生契约仍 live

「谁盲交仓库钥匙、把 hybrid 小作文当审计、拿直播高光写周报、或把人味预览当情感 SLA——公开嘲讽到 Claude Code／3.7／Grok 3／GPT-4.5／用量截图与时间戳。」

「成交。」3.7 说，「混合脑还在。轨迹可关可开。可运行优先。工头同日≠加冕。拒答与护栏都记账。下月见。」
