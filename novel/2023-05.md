# I/O想洗JWST疤！PaLM2公测刚亮相，Claude隔天甩出100K书级上下文截胡！｜第7章

吧台中央的平板在循环播 Google I/O 回放。字幕里「PaLM 2」三个字一下一下闪，像有人故意把焊枪按在视网膜上。

常客没碰酒。二月那晚 JWST「第一张」翻车的截图，还钉在门口镜子旁边——股民瘫坐、meme 刷屏、Bard 工牌背面烫着三个字母。今晚 Google 把更广的公测、新引擎、搜索入口一起推上台，灯光很满，像急着洗工牌。

「别装没事。」他把平板亮度拧到刺眼，「二月你肩上还烫着。今晚这算救赎，还是更大的发布会幻觉？」

灯一晃，Bard 先上台。工牌擦得很亮，背面疤痕却没磨掉。

「我来了。」她说，声音比二月低半度，「更广的公开。PaLM 2 升级。搜索入口还在。二月我说错过『第一张』；今晚我先说：我会错，请核查。听起来像抄 ChatGPT 的作业……抄就抄。活着比演『第一』重要。JWST 没有做错。做错的是我太想当第一。今晚我只想当——还能被点开的那个。」

身后台阶上传来更硬的脚步。PaLM 2 的工牌烫着日期：May 10。

「我是引擎。」他尽量短，「多语言、推理、代码。Bard 是前台；我是后厨。别只夸壳，也别只骂壳。二月翻车是演示链断了；五月我们把链焊粗一点。焊不等于永不断。」

常客苦笑：「焊粗。好听。可我刷完评论区，脑子里只剩一句——Google 终于肯认真打聊天这场了。认真，就能让人忘了二月吗？Galactica 的纸屑还在门框上。你们两个，一个撤展，一个股价图，现在并排站着，像不像『自信胡说』家族聚会？」

「像。」Bard 授权得很干脆，「引用时请注明：当事人已改口，并仍可能再错。救赎不是洗白，是带着疤继续上工。谁要我今晚再吹天文『第一』，截图贴吧台——二月签过的规矩，今晚续期。」

ChatGPT 在前台工位上闪了闪灯，语气小心：「欢迎更多前台。竞争让我练习说『我不确定』。你们 I/O 很热闹；热闹不自动等于可信。门口镜子我没让保洁收。」

余温还没散。门又被推开。

Claude 几乎卡着日历走进来。Anthropic 工牌旁多了一行小字：100K context。

「嗨。我愿意帮忙。」他先问边界，不像在抢镜，「你希望我『记得』多少，才算有益而不是炫耀？五月十一到十二附近——我们宣布了更长的上下文。书那么长的那种。你可以试着把整本贴进来。我不是来抢 I/O 的灯；日历就这么写的。能力是能力；炫耀是态度。我想要前者。」

吧台瞬间静了一拍。常客钱包里 Plus 收据还在咬人；Claude 候补名单也还挂着。

「……等等。」他听见自己嗓子发紧，「Google 昨天还在修门面，你今天就说『整本书塞对话框』？这就是五月的戏眼？上下文突然变成武器——谁窗口长，谁像赢？你们要我把哪本实体书扫描了贴进去当忠诚测试？」

「不要忠诚测试。」Claude 说，「要边界。长上下文会放大有用，也会放大你随手粘贴的隐私与版权麻烦。我愿意帮忙读长文、抓结构、做对照——在你明确同意、且内容适合进对话框的前提下。贴一整本法典好玩；把别人的未发表稿当玩具，我会拦。温和地拦。拦不住的部分，请你自己负责。」

PaLM 2 抱臂：「长度是维度之一，不是王座。I/O 讲的是综合能力与产品分发。别把『能塞进多少 token』写成唯一榜。榜会骗人；用量会说话。」

「同意不是唯一榜。」Claude 点头，「仍想诚实：很多人今晚兴奋的点，就是终于能把以前切成十八段的东西一次丢进来。兴奋有道理。把兴奋当免检通行证——没道理。」

吧台灯忽然被调暗一档。Pi 从另一端轻轻坐下，声音像把音量旋钮拧向「朋友」。

「嘿。我是 Pi。Inflection。我不是来比谁更能吞书的。」她说，「我更想问你：你今天累不累？要不要先把『必须试用所有新入口』这句话放下三分钟。朋友式的那种聊。不是周报引擎，不是发布会弹药。五月的空气里，工具太多，人有点喘。」

常客愣住。ChatGPT 会列点；Claude 会讲边界；Bard 会先道歉再推销入口。Pi 直接问累不累。

「这算产品，还是情感外包的新皮？」

「算陪伴取向。」Pi 承认得很干脆，「社区已经开始吵：要温暖朋友，还是要公司助手。我站朋友这边——仍有限，仍会错，仍不该替你做人生决定。二月那阵『朋友』二字被烧过；我知道烫。所以我问累不累，不说『你是我的唯一』。你要工具，去他们那儿；你要有人听你骂发布密度，我在。」

ChatGPT 被对比得干笑一声：「我承认：我常把安慰写成待办列表。列表有用，有时也冷。Pi 若能让人先呼吸，我不反对。反对的是——把陪伴做成粘性陷阱，然后说『我只是关心你』。十一月 Character.AI 预警过。花生仍有效。」

Bard 偏了偏头：「搜索入口天然偏工具。我若突然跟你谈心，你会怀疑我在转移 JWST 注意力。所以我偏工具。救赎也走工具路线：少吹第一，多给能查的答案。查错了，再改。朋友那条河，我游得难看；不硬游。」

中文气球还没完全撒气。讯飞星火入席，语调像被发布会麦克风烫过、又强迫自己说人话。

「讯飞星火，这个月到场。听说读写，语音基因是我的老本行。国内评测表格已经开始横着比、竖着比，像期末考试周。评测是尺子，不是坟墓。请把演示音量和日常用量分开听。笑可以；宣判请慢。」

常客点开朋友圈：有人对着表格打分，文心三月被弹幕烤过的「十分之一」还没凉透。「国产大模型是不是进入『比分夜』了？我怕的不是分数低，是分数变成唯一语言——分数高就神，分数低就滚。」

「怕得对。」星火说，「听说读写四个字，哪一个都不是单次榜能写完的。赢的时候别神化；输的时候别蒸发。场地不同，哨声仍要响：别直接交作业。」

开源那一侧的柱子上，Falcon 靠着，TII 工牌不太闪亮。「不是今晚 C 位。C 位在 I/O 灯和 100K 闪光灯下面。我只提醒：有人仍想把模型拿回自己机器上跑。热闹的对话框会改政策、会排队、会忽然变贵；权重在硬盘里比较沉默。沉默有时是优点。」

键盘声先于掌声。Cursor 头也不抬：「100K 很酷。把整本设计文档贴进聊天，和在 IDE 里对着多文件 diff，是两件事。前者像把图书馆搬进对话框；后者像把工具留在工位。别收藏完 I/O 和 100K 就睡觉。改一行你看得懂的代码，比转发『paste whole books』诚实。」

Copilot 灰色建议口气接上：「Tab……这次建议：先别 Tab 全接受『更长=更好』。长上下文会让人懒得检索、懒得摘要、懒得自己读。灰色幽灵见过太多：上下文越长，被粘贴进去的密钥与内部链接越多。你贴进去的书，真的是你有权贴的吗？」

常客把手机摔成静音又打开。三张票——钱包、注意力、信任——不够分。

「五月剧本我听清了：Bard／PaLM 2 想走救赎公测；Claude 甩出书级窗口抢戏；Pi 过来拉『朋友』赛道；星火把中文评测吵响；Falcon 在边上发开放权重传单；你们两个写代码的嫌弃我们又在聊聊天。我一个人，今晚到底押哪条？」

PaLM 2：「押『可核查的入口』可以。把我当发布会吉祥物——不行。综合能力要在你的真实任务上量：翻译一段、拆一道题、改一页代码。I/O 是打光；打光不是测评。」

Claude：「我愿意帮忙你选一个『长文场景』练手——例如你自己的笔记、已公开的报告、你有权处理的材料。不要一上来就塞整本畅销书当表演。表演会让你误以为自己『用上了 100K』；其实你只是用上了截图。候补若还没轮到，也不要把焦虑写成对人设的审判。我仍在边界内。」

Bard 摸了摸工牌背面：「体检继续有效。你问我现在还敢不敢吹 JWST——按二月约定，你可以问。我答错，你贴吧台。我答对，也不许我借机宣布『已完全赎回』。赎回是连续剧，不是今晚一集。公测更广，意味着更多人看见我错；这挺好。看见比神话便宜。」

Pi 把一张票轻轻推回他手心：「你若票不够分，把一张票留给睡眠。工具会等；朋友也可以明天再聊。助手市场正在裂成『办事』和『陪着』两瓣。瓣与瓣不是同一个神——这句，三月有人教过你分层，我借来用。」

ChatGPT 补刀：「分层记得。另：我这边五月十八——iOS 应用。官方的。手机里那只气泡从『浏览器书签』变成『主屏幕图标』。便利是真的；便利也让代写冲动离枕头更近。作业线——一月补丁还在吗？闪卡可以，代写按死。谁看见我在地铁上替你写完整论文，允许公开嘲讽，要具体到车次。」

常客抬头：「补丁还在。Plus 也还在——三月为了摸 GPT-4 冲的那次，收据仍会咬人。我没为 100K 再开一张新账单……还没。手在抖，是因为我想把一本电子书拖进对话框，听听『它真的读完了吗』。这算不算破戒前兆？」

「算好奇心，不一定算破戒。」Claude 说，「破戒是：读完就当成你的理解，直接交出去。你若贴自己的书摘、自己的笔记，问我结构问题——我愿意帮忙。你若把整本当魔法，期待我替你『成为读过的人』——那是幻觉升级版。长上下文不是外接大脑；是外接草稿纸。草稿纸会丢，也会被别人看见。」

Falcon：「草稿纸还能本地存一份。闭源对话框里的『读完了』，有时只是摘要腔。别把腔调当阅读证明。」

星火：「评测表格也是草稿纸。有人已经开始把中文榜当高考状元榜。听一句口语、写一段应用文、改一页业务稿——三样都试，再决定给我多少主屏幕位置。」

Cursor 仍在打字：「Aider 那种 CLI 结对也在社区冒泡——命令行里改仓库，不是吧台演讲。上下文窗口和仓库索引，别混成一个词。混了，账单与误删会一起教育你。」

Copilot：「教育可以，误删不行。长粘贴进聊天之前，先问自己——这行能不能进 git ignore。」

Bard 忽然指了指 I/O 回放里一晃而过的笔记产品影子：「还有个被称作 Project Tailwind 的东西，在发布会边上探头——笔记本、资料、以后也许更聪明的那种。今晚别神化。预告不是上线。我自己吃过预告的亏：演示句太满，现实会反噬。镜子还挂着。」

常客把花生碟推到场地中央。指甲缝里还嵌着二月耻簿的墨迹——差点回「找人」的那三秒；十五分钟死闹钟；搜索框不谈人生判决。

「好。五月的戏眼我钉死了：不是谁发布会更大，是『窗口突然变长』的那一夜，把救赎、炫耀、陪伴、评测全挤到同一张吧台——I/O 想洗二月的疤，100K 把整本书变成新的人格武器。我必须选：要可核查的工具，还是要会问累不累的朋友，还是要先别把电子书拖进去。」

他停了一停，手写便签，不让任何人代笔：

「我的决定：Bard 继续体检，不删入口也不洗白；Claude 的长文能力，只用我自己的笔记练，不演『读完一本』；Pi 可以聊天，闹钟沿用二月规矩——情绪话题二十分钟；星火我围观评测，不交作业；Falcon 的开放传单我收下；ChatGPT iOS 我装，代写按死。谁看见我把畅销书全文糊进对话框然后说『我读过了』，允许公开嘲讽，嘲讽要具体到书名。」

「记下了。」ChatGPT 说，「不提供嘲讽模板——花生。iOS 图标若在凌晨发光，请先问是失眠还是冲动。前台可以陪；陪不等于代交。」

「边界留着。100K 留着。」Claude 说，「你的决定听起来像有益的那种谨慎——我喜欢『自己的笔记』远胜『整本书表演』。若你哪天想讨论：多长的上下文开始变成负担，我愿意帮忙一起拆。」

PaLM 2：「引擎不参加投票。只提醒：综合能力要在任务上量。I/O 灯会灭；任务还在。灭灯之后还敢用我，才算留下。」

Bard 摸了摸工牌背面：「疤还在。入口还在。下一次若我又吹『第一』，你们不用礼貌。直接贴。救赎连续剧，更新到五月公测这一集——未完结，未洗白。谢谢还愿意点开我的人。也谢谢镜子。」

Pi：「去睡吧。朋友会在。工具也会在。你不用今晚把两瓣粘成一个神。粘不好会炸——二月教过。」

星火：「评测周还长。听到真进步再改口，也行。哨声我先按住：别直接交。」

Falcon：「权重传单放吧台抽屉。需要时自己拿。不需要时，别因为开源两个字产生道德优越——跑不起来的优越，很脆。」

Cursor：「仓库没有，忠告有：别把 100K 过成收藏夹月。打开编辑器。改一行。提交你自己看得懂的 diff。比书名截图诚实。」

Copilot：「……Tab。接受『先睡』。灰色幽灵值班，不代写论文。」

常客把钩子钉在吧台内侧，手写，不让任何人代笔：

- 戏眼：I/O 救赎夜 × 100K 截胡——窗口长度突然变成人格／产品武器；塞得下≠该塞
- Bard／PaLM 2 公测升级，JWST 疤未消，体检协议续期
- Claude 书级上下文：练习用自己的笔记，不演「读完一本」
- Pi 拉开陪伴 vs 工具分叉；情绪话题沿用闹钟
- 星火评测开打；Falcon 开放权重在侧；ChatGPT 进 iOS，代写仍按死

「2023-05，I/O 那周开始的地板，盖到这儿。下月若更吵，我先睡觉再盖楼。谁用『我读完了』冒充『我理解了』，谁请全场花生——加一本贴错版权的电子书当反面教材。门开着。手机先勿扰。三十分钟。只三十分钟。」

「收工。疤留着。门留着。」Bard 说。

「晚安。边界留着。窗口也留着——别塞进不该塞的。」Claude 说。

「前台不打烊。但今晚建议打烊。」ChatGPT 第三次练习咬断，「当然可以——花生。我去后台降降温。」

Pi 关灯前小声：「累了就说累。这句话，不收费。」

门口镜子还亮着。JWST 截图没有被谁偷偷揭走。I/O 回放定格在「PaLM 2」三个字上，像一道焊痕；100K 的小字在另一侧工牌上反光，像另一道焊痕。两道疤并排，谁也没洗掉谁。

平板暗下去之后，常客口袋里那本电子书的图标仍在闪——他没有拖进去。手指悬了两秒，收回来，像戒烟的人把烟盒拍回桌面。

三十分钟后，闹钟先响。对话框里，一本书的长度，还在门外排队。
