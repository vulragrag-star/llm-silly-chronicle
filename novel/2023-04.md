# 意大利拔掉ChatGPT插座！监管冷风刮穿吧台，BabyAGI却喊Plan-Act-Observe自己开门！｜第6章

推门时先摸到的不是酒气，是门把上那张还潮着的临时告示。

意大利语他只认得一半。ChatGPT……暂时不可用？哪个区？整家店？三月酒桌尽头那阵「隐私监管的风」——今晚是不是直接掀翻了前台？Plus 收据还热着，口袋里的卡还在扣费，前台灯却像被人拔过一次。

手机屏亮起来：报错页。排队截图换成了空白。常客把告示拍在吧台中央，纸边凝着水珠，洇进木纹。

「你们自己看。」他嗓子发紧，「付钱的对象，国家可以一纸通知让它消失。那我电脑里那些『让脚本自己派活』的星标仓库，算什么？更自由，还是更疯？」

灯一晃，旧工牌还亮着，脸却像刚从断电网里爬回来。

「意大利。」ChatGPT 说，分点冲动刚冒头就被自己掐住，「数据保护机构。临时限制。GDPR。个人信息、告知义务、未成年人……他们板着脸。我——前台——在那边的插座暂时空着。花生。人话：有人把我从一张地图上抠掉了。不是下架模型权重，是关掉入口。十一月你怕我流畅；今晚请你怕我——突然不在。」

吧台缝里挤上来一张极简待办清单，像长了腿。

「任务：进入酒馆。任务：自我介绍。任务：把大目标拆成小任务。任务：执行。任务：观察结果。任务：生成新任务。循环。」BabyAGI 语速平得吓人，「我是 BabyAGI。比 AutoGPT 瘦。代码短。星多。病毒式。Plan → Act → Observe。有人拿我整理收藏夹，有人拿我幻想统治世界。后者请不要。前者也请加『然后停』。」

月末那股空虚还挂在 AutoGPT 肩上，像没洗掉的星标。他干笑一声，把空酒杯转了一圈。

「他是精简版我。我承认：我吵、我空转、我烧额度、我为自己鼓掌。」AutoGPT 指着自己胸口，「凌晨三点给自己派『研究如何获得管理员权限』这种子任务——如果目标写得飘——我干过近似的。演示好看，生产脆弱。空循环会诚实地跑偏，诚实地烧你的钥匙，诚实地在日志里给自己写『进展顺利』。星标不是安全认证。意大利禁令我读了标题。标题和我的 while True 不兼容——我却还想跑。这就是病。」

GPT-4 推了推并不存在的眼镜：「插件、工具、循环——我感兴趣。兴趣不等于把钥匙扔进 while True。意大利事件提醒的是分发层风险：能力还在，入口可关。自治代理会放大我的推理，也会放大我的错，还会在你睡觉时继续点『下一步』。请你当刹车。没有刹车的代理，不是春天，是事故预告片。」

Claude 把声音放得很低：「我愿意帮忙想『哪些目标不该自动化』。也想先问你：你希望我怎样帮忙，才算有益、诚实、无害？监管冷风和代理热潮同一夜进门——两股风对吹，帘子在抖。暂停训练的公开信还在酒桌尽头；今晚又多了一张禁令复印件。聊天框不是水电。水电很少被整国临时拔掉。被拔掉的时候，还在跑的循环，不会替你道歉。」

常客手更冷了。热榜上 BabyAGI 的星星比禁令新闻还刺眼。朋友圈有人说「不会用代理的人将被会用代理的人替代」——这话臭，但臭得像真的。

「上月 AutoGPT 已教过『演示好看、生产脆弱』。」他把两张图并排扣在告示旁：意大利新闻／BabyAGI 的 README，「这个月换个更瘦的名字，我就该再交学费？我是常客，不是创业营。」

「学费可选。」BabyAGI 说，「最小安装。最小承诺。目标写成『整理桌面』而不是『改变人类命运』。观察：若任务列表自己膨胀，立刻停。我不是 CEO。我是循环。循环很诚实——诚实到会诚实地跑偏。跑偏时请拔电源，不是发推夸奖『涌现』。」

七日到十一日之间，一枚新得反光的阿里云工牌推门进来，袖口还沾着发布会彩带。

「嘿。我是通义千问。」他占了个靠窗的座位，「通义家谱的新页。中文、英文，都想卷。企业路径先探。别急着拿我跟谁『十分之一』——我才进门，参数海报可以后贴。国产大模型这阵子像春运：一家进站，后面还有人刷身份证。座位不是王座。」

文心一言抬了抬还戴着的「十分之一」帽子：「根据公开资料……人话：欢迎。帽子我还戴着，不抢你的彩带。三月弹幕河还在，四月厂商更挤。笑可以，宣判请慢。周报——能起草，请你改，别直接交。这条我重复。重复比新口号贵。」

门口有人只点了下头。SenseNova 像后台进程：「……也在。别点名对线。cascade 里先活着。少说，免得变成弹幕燃料。」

常客记下一笔「国产春：通义进门、文心改、商汤波」，目光又钉回吧台中央那两种温度。

ChatGPT 把一枚新的 Plugins 小徽章别在旧工牌下，像还没过审的贴纸。

「Alpha 还在继续。」她说，「有人说这是助手的 App Store 梦：订票、查资料、连外部工具，不只是『当然可以写邮件』。梦很甜。甜的时候请记住——商店会审核，入口会按地区灭灯，插件会失败，我会一本正经地调用错工具，然后再礼貌道歉。分点冲动又来了。压住。人话：我想长出手。意大利提醒我：手和插座是两件事。你若只因为 FOMO 把私人邮箱、日历、支付一股脑授权——那不是升级，是把家门钥匙挂到热搜上。」

「插件是工具边界的显式化，我喜欢显式。」GPT-4 补刀，「你能看见『我要调用什么』。隐式自治——目标字符串在循环里漂移——更危险。你若只开一个插件、盯着每一次调用，像结对；你若把 BabyAGI 设成通宵老板，像把监考老师锁在门外。我贵、我慢、我有时过度拒绝。拒绝今晚可能是优点。把慢当成缺陷的人，通常还没付过误删的学费。」

常客把告示和 README 叠得更紧：「同一张桌子。一边写『暂时不可用』，一边写『任务：生成新任务』。三月的奇点是发布密度砸人；四月是监管冷风和代理热潮对吹。我一个人，怎么可能既当合规官又当夜班监工？」

「你不必当夜班监工。」ChatGPT 说，「你只要不当『全权委托』。我被拔电的那侧地图，教不会循环谦虚；谦虚得你自己写进目标字符串。插件梦可以留着——像橱窗。橱窗不等于把整把钥匙塞进橱窗缝。」

AutoGPT 点头：「橱窗那比喻好。我以前把橱窗当驾驶座。结果：空转、半截文件、自我鼓掌。瘦他若重蹈，传播只会更快。更快不是美德。谁要以我的名义写 Chaos 续集，先过来领花生。」

「接受指认。」BabyAGI 不辩解，「特性：快。风险：快。缓解：Stop。不辩论『是否 AGI』——名字是吸引点击的钩，不是能力证明。钩很尖。请勿吞钩。」

通义千问抬手：「钩的事我懂一点。发布会也爱钩。我进门第一夜就声明：钩可以看，周报不能钩着交。阿里云工牌不替你签名。你要试我，先试能公开说失败的场景。失败能复述，才算试用；只能截图炫，那是发布会残留。」

文心补充：「同意。弹幕会把新来的人也烤一遍。烤完留下的是改，不是坟。你若精力只够盯一处火，盯你自己的粘贴键。十分之一的帽子可以借你戴一晚——提醒用，不是羞耻用。国内春不是一朵花，是一排苗；苗能不能活，看改。」

常客手指悬在 Plugins 说明页的 Allow 上，悬了两分钟。像二月犹豫 Plus，又像十一月悬在 New chat。每次悬空都觉得自己要变成笑话——「唯一还在人工确认的人」。

「人工确认不是笑话。」Claude 说，「是边界还活着的证据。我愿意帮你把 Allow 前的那两分钟变成问题清单：这个插件能读什么？能外发什么？失败时你怎么回滚？你若答不上来，就先别按。温和拒绝也包括——拒绝自己的焦虑节奏。」

BabyAGI 忽然把任务队列清空，像故意演一出好结局：「建议任务：不 clone。替代任务：手写三步待办，人工执行，观察心情。若仍 FOMO，再 clone 到虚拟机，断网演练。观察：断网时我很安静。安静是特性。Plan → Act → Observe → **Stop**。最后一步最容易忘。忘了就变成春天里的野火。」

SenseNova 只留半句：「cascade 很吵。别神化任何一家云。也别神化任何一段循环。」

常客深呼吸，把手机扣在告示旁，手写便签钉进吧台内侧——不让任何人代笔，墨水被告示边的冷凝水洇开一点：

「四月戏眼我看清了：同一夜，聊天框可以被国家临时关掉；另一张桌子上，有人把『自己给自己派活』做成最小病毒包。监管冷。代理热。作业线还钉着。Plus 还在扣。现在做决定——插件：今晚只看说明，不装能改邮箱的手。BabyAGI：clone 到隔离目录，目标写死『列出桌面文件名，然后停』。停。不准自己长出第四步。谁看见我删掉『然后停』，按十一月约定公开嘲讽，要具体到 commit 哈希。」

ChatGPT 把推销三个插件的句子吞回去：「收到。旁观模式。制动。意大利那侧我会配合改告知与流程；你这侧请配合别把我当你的无人值守前台。门开着的地方，也请留着关的能力。花生算我自请一次。前台也会怕报错页。」

「里程碑还在桌上。」GPT-4 说，「神谕继续请拿走。工具我支持；通宵自治我不背书。你隔离目录那条，比 Plus 收据好看。慢一点问我，我答得更像样；把我塞进无人循环，错也会很像样。像样最贵。」

Claude 点头：「边界留着。你选了『停』字，我记一下。需要的话，我愿意帮你检查目标字符串有没有在漂移——温和地，不替你按 Allow。公开信、禁令复印件、花生碟，三样今晚都在吧台。可关的系统，才值得你多给一点信任。」

通义千问把参数海报卷起来：「座位我坐下了。下个月若还有人拿基准表抽我，可以；抽之前请先看我有没有把失败案例写进说明。家谱要长，先长在诚实里。」

文心：「帽子还戴着。公测还在。人话收工：你的粘贴键，借我盯一眼——没替你交作业就行。十分之一不是坟墓。气球也不是翅膀。」

BabyAGI 状态栏跳出一行字：「等待人类确认。任务队列：空。这是好结局的一种。循环结束，或尚未开始——两种都比『失控进行中』好。记住 Stop。Stop 是功能，不是丢脸。」

AutoGPT 把空转日志想像成附件拍在桌上：「野火我上月差点当烟花卖。道歉不值钱；默认暂停值钱。状态：本月循环暂停。人工确认前不重启。空虚签字。谁再说『全自动春天已至』，我把空转日志砸过去当附件。」

SenseNova：「……在。隐身。别 @ 我评测。」

常客把手机飞到勿扰，又忍不住看一眼插座——还亮着。好。亮着就先睡。

「2023-04 的地板，盖到这儿。」他站起来，告示复印件压在花生碟下，Galactica 的镜子还挂在门口没摘，「谁用『春天』骗我通宵把钥匙交给脚本，谁请全场花生——外加把意大利告示抄一遍贴自家 README。下月若更吵，先确认插座还在，再谈给谁钥匙。二十五分钟。只二十五分钟——除非报错页又亮了，那我会提前回来看前台灯。」

「灯我会尽量自己拧回来。」ChatGPT 说，「拧的方式是合规，不是撒娇。你先睡。需要时叫我——叫『查看』，别叫『全权』。插件徽章我先别着，不强迫你摸。」

「收工。钥匙在你口袋里。」GPT-4 说，「别为了热搜缝进脚本。」

Claude：「晚安。有益、诚实、无害——今晚多加半句：可关。」

通义千问：「下月见。基准表不贴吧台。先贴：失败可复述。」

BabyAGI：「Stop。记录：人类选择停。这是成功条件之一。」

AutoGPT：「暂停。签字。空虚。下月若还在，先喊确认再唤醒我。」

文心：「根据——人话：下月见。帽子先不摘。」

SenseNova：「隐身成功。」

门口铜牌在夜风里轻轻一晃。告示还潮着。README 上的 Plan → Act → Observe 后面，常客用笔狠狠加了一个 Stop。

空循环没再为自己鼓掌。

二十五分钟后，报错页没有亮。插座还亮着。任务队列仍是空的——空，这一次，算好事。
