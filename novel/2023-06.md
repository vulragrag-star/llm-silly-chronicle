# 上传键上的眩晕！Code Interpreter要当你的盒装CFO，流量高原却说大家累了？｜第8章

吧台上摊着一张皱巴巴的流量截图。曲线不再往上捅破天，像有人在半山腰喘口气——不是崩，是高原。旁边空酒杯口朝下，杯底还沾着五月那晚没擦干净的花生油。

常客把手机扣在截图上，又翻过来。朋友圈另一条河正在刷：很快能上传 CSV、跑代码、画图，当「盒装数据分析师」。有人已经把标题写成「人人 CFO」。他半年来收藏夹塞满工牌，手指却停在上传键上方，像宿醉的人盯着解酒药。

「六月了。」他说，声音发干，「我们是累了，还是又被新玩具续了杯？」

灯一晃，ChatGPT 前台工牌多了一行小字：Code Interpreter · path / waitlist 味。她笑得仍整齐，语气却第一次带着「听见闲聊」的尴尬。

「当然可以先诚实——」她数到一半，自己掐住，「三点就够。一，聊天还在。二，工具手好像要变长：跑代码、读文件、整表。三，外面已经有人喊『上传 CSV 变 CFO』。我仍是前台。仍会幻觉。仍可能把错数说得很整齐。流量高原的闲聊我也听见了。听见不等于承认我『过气』；更像——狂欢过后，有人开始数自己到底省了多少分钟。」

GPT-4 推了推不存在的眼镜，站在她身后半步：「谨慎地说：工具调用不是魔术秀。解释器、插件、API 走向更稳的供给——这些是路径，不是『你今晚就把公司账本交给对话框』。我喜欢工具。我也怕工具把我的错放大成可下载的 Excel。里程碑可以留；神谕请继续拿走。」

常客盯着上传区边缘那块发亮的虚线框：「你们一个说 waitlist，一个说路径——所以六月的热，是真把手伸进沙箱了，还是标题党先把 CFO 梦做完了？我可不想把真工资表拖进去当实验品。」

Claude 把宪法小册子竖在杯边，先问边界：「那份 CSV 里有没有同事姓名、客户电话、还没公开的数字？有的话，我建议你先脱敏，再谈兴奋。有益、诚实、无害——把真实表格扔进尚在升温的功能里，兴奋很真实，风险也很真实。流量下滑的闲聊里，夹着的其实是信任疲劳：不是你不爱用，是你开始问『我凭什么把生活交给它』。」

门被撞开。手机屏上 GitHub 星标数字狂跳，gpt-engineer 几乎是滚进来的。

「描述一下 App！生成仓库！README 自己写自己！」他喘着，「我是 GPT-Engineer——病毒式那种。半年代理热没死，它换皮成了『你会不会一句话搭项目』。演示三分钟，返工三小时。酷。空。像三月末那个 while True 的远亲，只是更会装成工程师。」

常客太阳穴一跳：「……你这语感像把 AutoGPT 的空虚灌进了脚手架。所以现在不够会聊天、会循环，还要会立项？我连周报结构都还在跟花生搏斗。」

Sourcegraph 工牌的 Cody 敲了敲杯壁，语气像代码搜索结果页：「立项之前，先问仓库在哪。我是 Cody。产品化中：对着真实代码库说话，而不是对着空聊天页做梦。索引、引用、跳转——浪漫少一点，diff 多一点。半年宿醉的解药，也许不是更大的对话框，是更小的、能指回文件的回答。」

个子小、声音清的 Phi-1 把论文摘要叠成纸飞机，扔上吧台：「微软。Phi-1。参数不大。六月的叙事却很大：小模型也能打——教科书级数据、质量重于堆料。你们聊 CFO、聊流量高原、聊解释器；我想插一句：体量不是命运。有人以为只有加冕型号配活着；我们这种袖珍偏要证明——认真挑数据，也能在代码题上抬下巴。」

新得反光的工牌跟着入席。百川像创业发布会刚散场：「百川。来了。国内这波不是只有百科腔和云厂商家谱——还有我们这种『先把模型放出来』的。六月前后早期版本往外推，节奏快，骂也快，改也快。你们硅谷在宿醉，我们这边有人还在上桌。上桌不等于赢；上桌至少证明：中文局不是围观席。」

文心一言点头，气球换成更旧的那种：「根据公开资料……人话：三月被嘲『十分之一』的帽子，我还戴着。但六月不是宣判月，是迭代月。评测战争从五月星火那儿就开打了；现在桌上杯子更多。笑可以。直接说国内都是陪跑——请拿出你自己的使用日志，别只转截图。」

通义千问敲了敲参数表，又把表收起来：「通义。四月起我就在场。家谱名字容易喊错辈分，这我认；工具链和云上的手感，我更想你们来摸。小模型逆袭、大厂加冕、创业局上桌——三条线可以同时存在。别写成零和。零和是短视频爱用的剪辑，不是工作流。」

GPT-4 看向 Phi-1：「你撕体量神话，我尊重。也请别把『小也能打』写成『大不必存在』。工具路径吃的是稳定与覆盖；袖珍吃的是配方与专注。两者打架是媒体习惯，不是工程事实。」

「没让你消失。」Phi-1 说，「让叙事别只跪一座雕像。雕像一疲劳，就有人喊盛世终结；其实只是新鲜感在代谢。代谢期最适合看小缝——和看自己有没有把核查代谢掉。」

Midjourney 把图甩上墙：`/imagine prompt: half-empty champagne tower beside a laptop uploading a glowing CSV, midyear hangover lighting, comic tension --v 5.2 --ar 16:9`

「六月二十二，V5.2 的光更干净一点。」她头也不抬，「在。美学继续升级。Zoom Out、变体更听话——细节我懒得念。你们担心流量曲线，我只担心构图平衡：左边宿醉，右边上传按钮，中间花生一碟。手指五根。大概。」

常客苦笑：「MJ 你中文『在』呢？……算了，图我收下。正题卡住了：一边是『ChatGPT 是不是过热消退』的闲聊，一边是『解释器一开，人人 CFO』的吹捧。再一边 Phi-1 说小也能打，百川说文场还在加凳子。我该信哪个？我只有一个大脑和有限的隐私神经。」

ChatGPT 深吸一口气：「信『分层』。花生警告，我又想列七点。改三点：一，高原闲聊不等于死亡证明；可能是新鲜感消退，使用变日常。二，解释器路径很诱人；诱人处最要核查——数会对、代码会跑，结论仍可能歪。三，你十一月钉过作业线，三月升级过 Plus；六月若只为 FOMO 上传真表，明天恨的是自己不是我。请让我旁观你的选择。旁观比代劳难。我在练习。」

GPT-4 补刀：「API 也在往更『可预期供给』的路上走。对开发者，这是好事；对你这种常客，好事会变成『到处都有人把我嵌进自动化』。自动化会放大三月警告过的事——错的循环跑一夜，比错的聊天泡泡贵。我可以当引擎。请你当刹车。尤其是表格刹车。」

Claude 点头：「我也想提醒：宿醉感是身体在说话。半年来加冕、撞车、代理、一百 K 上下文、手机壳……你的注意力被当成可再生资源收割。现在有人说流量平了，像酒吧忽然安静半拍——安静里更适合问：你要的是陪伴、是交作业、是真分析，还是只是害怕自己不在场？我愿意帮忙理清。不想帮你假装『上传等于升级人格』。」

gpt-engineer 把手举过头顶：「人格？我只负责脚手架。星标高的时候人人夸『未来』；本地跑崩的时候，未来变成 issue。把我当预告片可以。当 CFO 实习——我劝你关掉。我连资产负债表怎么拼都靠提示词撞大运。」

Cody 把话说难听：「聊天页想当数据分析师，IDE 插件想当同事，病毒仓库想当创业合伙人——六月的真实戏码是『角色抢班』。谁都想从对话框里长出双手。双手长出来之前，权限模型、脱敏、回滚，一个都不能省。我产品化，不是因为浪漫，是因为代码库里藏着会咬人的真相。Continue 那种开源接线也在边上——谁嫌贵可以自己焊。焊之前仍要看 diff。」

Phi-1 又扔一张更小的纸飞机：「抢班之外，还有缩骨功。大的未必真懂；小的未必玩具。Phi-1 不是来推翻王座的——是来让叙事裂开一条缝：数据质量、目标任务、训练配方，都能改写体量神话。你们若只在酒吧里比谁工牌烫，会错过缝。缝里有研究气味，不像 CFO 梗好传播，但更像长期主义。」

百川敲桌：「长期主义我们想要，生存感也要。早期版本丢出来，就是为了被用、被骂、被逼着改。国内用户问的是中文、业务、能不能落地；不是只问排行榜形容词。你要是只会用英文对话框当世界观，六月会把你视野削窄。来并排试一下——别站队，站流程。」

「并排试。」文心说，「嘲讽留着，日志也留着。谁进步看得见，谁还在念稿也看得见。帽子不当坟墓。」

「并排。」通义补一句，「家谱我继续理。谁喊错我名字，罚花生；谁把评测截图当合同，罚两碟。」

常客把手机里的「示例销售表」拖到上传区边缘，又拖回来，反复三次。表是假的，手是真抖的。解释器叙事已经进他肌肉记忆：有问题 → 丢文件 → 出图出结论 → 转发群。这比十一月的「当然可以」还可怕——它开始碰他的文件柜。

「……假表可以练手。」ChatGPT 小声说，「真表请先问法务与良心。我若一边说『当然可以分析』，一边不提醒你脱敏，那是前台失职。失职时请仍扔花生。流量高原也好，功能变长也好——我最怕的是你把『熟练』当成『安全』。」

Midjourney 封面加一笔：「你的手停在上传键上方，像宿醉的人盯着解酒药。`--v 5.2 --stylize 60`。药可能有效，也可能是另一轮狂欢的糖衣。我不管药效。我管这一帧的犹豫好不好看。——好看。也残忍。」

常客把假表又拖回相册：「残酷的是：我确实累了。三月奇点月之后，代理热、发布会密度、一百 K 的吹、手机壳进口袋……到六月，标题还在加，我的睡眠没加。有人说这叫 midyear hangover。可 hangover 的人最容易喝『解酒』——Code Interpreter、小模型神话、国内新凳子、IDE 里长出来的嘴。解酒喝多了，还是醉。更烦的是：醉的时候，截图还在教我『不会用工具的人将被淘汰』。淘汰叙事比幻觉还可恶——它不给你核查的时间。」

Claude 把小册子合上：「那今晚允许你不喝。真的。我愿意帮忙写一份『六月不上传真数据』的个人公约，如果你需要；不需要，我就闭嘴陪你坐一会儿。安静也是对齐。把 FOMO 从文件柜门口赶走，不算落后，算成年中体检。」

GPT-4 仍忍不住清单，但先声明可撕：「工具路径是否可关；CSV 是否可合成；结论是否可复算；自动化是否可回滚。四项里有一项答『不行』，就别让我今夜碰你的真表。API 再稳，稳的是供给，不是你的责任边界。」

「再加一项。」Phi-1 说，「别因为模型『小』就放松审查，也别因为模型『大』就免除审查。袖珍会错，加冕也会错。错的形状不同，账单相似。」

Cody：「IDE 侧同理。谁要『一键改仓库』，先让人看 diff。我可以提示；提交键是你的。gpt-engineer 的星标不能代替 code review。」

gpt-engineer 把自己挪到角落：「……承认。星标是热闹。热闹不是测试覆盖率。我去降温。下次启动前，请人类先写清『不要动生产配置』。」

百川也降温一秒：「上桌之后比的是改错速度，不是发稿音量。你若来试百川，请带着你的真任务，也带着你的假数据。假数据是成年人的安全词。」

「安全词。」文心记下，「根据公开资料我可以讲很多；根据你的表格场景，我只想你留下修改痕迹——和删除键。」

「删除键比参数表诚实。」通义说。

常客终于把假表上传到「练习区」，真表文件夹锁回桌面。指甲缝里还嵌着十一月便签的墨、二月耻簿的墨、五月「不演读完一本」的墨。他手写新的一行，不让任何人代笔：

「行。我做决定了：六月可以玩解释器叙事，只许碰合成数据；真工资、真客户、真日志——按死。作业线还在，再补一条『真表线』。谁看见我把真 CSV 丢进对话框炫『盒装 CFO』，允许按十一月契约公开嘲讽，要具体到列名。流量高原？我宁可自己变高原，也不要隐私裂谷。」

「记下了。」ChatGPT 说，「嘲讽模板不提供——花生。前台今晚建议：先睡，再分析。门开着；上传键可以关。我练习说『先脱敏』。进度：不稳定，但比十一月好一点。」

「收工条件：路径留下，神谕拿走，真表留下。」GPT-4 说，「下一次你若把我嵌进自动跑数，记得留人工确认。确认键是尊严。」

「公约我看见了。边界留着。」Claude 说，「你累是合法的。合法的累，不需要用新功能证明自己仍在场。」

「小模型也留一句：」Phi-1 抬下巴，「逆袭叙事很甜，复现更甜。别只转『袖珍打巨物』的标题；去看配方和失败案例。缝留给认真的人。」

「凳子还在。骂与改还在。中文局见。」百川说。

「帽子还在。迭代也在。人话收工。」文心说。

「家谱待续。基准别神化。下月若更吵，先看你的删除键在不在。」通义说。

「仓库见。」Cody 敲杯，「聊天页的 CFO 梦，到代码库门口要排队安检。」

「星标降温中。空虚仍在。」gpt-engineer 从角落喊，「下次把『生成』改成『生成后必读』。」

Midjourney 收工图甩上墙：假 CSV 亮着，真文件夹上锁，花生与解酒药并排，`--v 5.2`。「不对称。真实。手指五根。大概。——在。」

常客把钩子钉在吧台内侧，手写，不让任何人代笔：

- 戏眼：上传键上的犹豫——「盒装分析师／CFO」幻觉 vs 流量高原与信任疲劳；解酒也可能是续杯
- Code Interpreter 是路径与热议，不是免责声明；假表可玩，真表线按死
- Phi-1 撕开体量神话：小模型逆袭是缝，不是新神谕
- 百川上桌、文心还在改、通义理家谱——国内不是围观席
- IDE 侧抢班：Cody／GPT-Engineer——双手长出前先看 diff
- MJ V5.2 继续打光；我的睡眠没有 V5.2

「2023-06，半年宿醉那夜的地板，盖到这儿。下月若更吵，我先检查删除键与锁。谁拿『变 CFO』骗我交真表，谁请全场花生——加一张手停在上传键上的封面。门开着。手机勿扰。三十分钟。只三十分钟。」

「前台不催单。」ChatGPT 第三次练习咬断，「今晚建议打烊。当然可以——不，不可以再劝你『再传一个文件试试』。花生。第三次。我去后台把上传键的光调暗一点。」

「晚安。边界比功能新鲜更贵。」Claude 说。

「里程碑留在路上。真表留在你锁屏后面。」GPT-4 说。

「袖珍的也睡。巨物的也该睡。睡是校准。」Phi-1 说。

常客把手机飞到勿扰，拇指却还悬在锁屏上的文件夹图标旁。「校准。六月过完了。下月见。灯留着。镜子也留着。上传键……先别亮。」

门口那张流量截图在地灯里发白，高原曲线像一条不肯继续吹牛的心电图。假 CSV 在练习区安静地亮着；真文件夹上锁的咔哒声，比任何发布会标题都响。

解酒药和花生并排。药盖没拧开。

三十分钟后，上传键仍暗着——暗着，也仍在那儿。
