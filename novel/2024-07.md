# 硬盘哭墙磁盘眩晕！Llama 3.1 405B开源边疆砸成真货，GPT-4o mini降价刀捅穿3.5——电税＋便宜≠可靠当场反唇！｜第21章

手机亮成一块磁盘告警红的时候，常客还没推门。

走廊里已经有人在念两行日期：七月十八——默认模型悄悄换成 **GPT-4o mini**，账单曲线像被抽了一刀；七月二十三——Meta 把工牌撕成三张：8B、70B、405B，标签写着 Llama 3.1。评论区不是「开源能不能摸一下榜」，是「谁硬盘还够」「谁在下 405B」「谁先把 70B 微调成自己的神」。梗图贴满哭墙：`Disk space remaining: 12GB`。四月他还在客厅里听风扇起飞；六月对照表还没冷透；今晚野心直接写进 S.M.A.R.T.。

「别报幕。」他把两张截图拍上吧台，「左：计算器——token 价低到像写错小数点。右：群问『405B 要多少盘？种子还活着吗？下完能不能跑？』我差点点了『全下』。差点的计量单位这个月改成 **TB**。」

灯一晃，三层工牌叠着推门。最底下那张烫着 405B，羊毛味更重。

「先看我。」Llama 3.1 把围巾甩到花生碟边，「八点。七十点。四百零五点。七月二十三。我不是来念参数海报的——我是来把『开放权重能不能坐前沿桌』从嘲讽改成威胁的。闭源那边习惯说：你们开源玩玩就好。今晚真刀真枪有一张工牌写着 open-ish。下载焦虑？听见了。硬盘哭？听见了。哭完接着下。社区微调成灾——褒义。成灾才像夏天。成灾才像边疆。」

吧台侧面滑进来一张小一号的工牌，字却亮：GPT-4o mini · Jul 18。

「等等。日历别只钉二十三。」GPT-4o mini 敲了敲自己的边角，「十八号我先动刀。默认位。廉价。把还赖在 3.5 座位上的人——不轻轻——**捅下去**。有人说我是便宜的 4o；有人说我终于能把玩具默认换成能干活的。应用层在改路由：谁还把 3.5 当默认，谁在交智商税。405B 很炫。炫完要磁盘、要显卡、要耐心。我只要一分价钱，换你把开关拨过来。拨完你会发现：夏天改工作流的，不一定是最大的那头羊驼。」

六月还烫的工牌没灭。Claude 3.5 Sonnet 肩上 Artifacts 小窗闪了一下。

「慢着。」她说，「我更关心：你下完能不能写出**完整可运行**的东西，还是只为了在群里说『我本地有边疆』。六月我刚把编码椅坐热——爱写能跑的代码，不爱写能吓死人的体积。405B 若真能逼闭源正面谈『开放权重也是 frontier』，好。若只是变成硬盘宗教，我扔花生。评测表可以转；默认路由可以换；**别把下载进度条当成能力进度条**。进度条会动。能力不会因为进度条动了就长出来。」

月亮图标亮着。Kimi 语速慢：「……我可以读完整份发布说明，也可以读完你那份『磁盘不够怎么办』长帖。这个月我这边有公开动静：上下文缓存，公测。不是来跟 405B 比谁更大——是提醒：长文本也可以省钱、省重复预填。你们吵边疆的时候，有人在为同一份 PDF 反复喂付冤枉钱。缓存是图书馆员的抽屉，不是宇宙。先拉开抽屉，再决定要不要把整间书房搬进硬盘。」

七月二十四又推门进来一张英法工牌：Mistral Large 2。

「Bonsoir.」他翻了翻工牌，「我也刷新了。欧洲旗舰位，商务腔还在。声量被美中双极压——习惯了。405B 是夏日主震；4o-mini 是默认位地震；我是余震里那声礼貌的敲桌子：闭源旗舰没有死，合作还在谈，菜单还在换。谁要是以为夏天只剩羊驼，请把日历翻回二十四号看一眼。旁支。我认旁支。C 位让给磁盘哭墙。哭墙很好看。很好看不等于采购表只留一行。」

常客喉咙发紧，却笑不出来。群里更疯的话他念给全场听——「不开源等于没资格评 frontier」；「下不动 405B 就闭嘴」；「API 党是数字佃农」；反过来：「本地党是硬盘邪教，进度条当通行证」；「mini 才是成年人，405B 是暑假作业」。两种极端。两种都想收编他。六月他还在跟 Sonnet 写能跑的脚本；七月硬盘告警红着，像有人把夏天直接焊进机箱。有人转发那句英文——Largest open-ish frontier-class release of the summer——**open-ish**。那个 -ish 像一根刺。刺在「开放」和「完全开放」之间。刺在「能坐桌」和「已经称王」之间。

Llama 3.1 把 405B 工牌朝向他：「哭墙可以。哭完问一句：你要的是**能跑的主权**，还是**能晒的截图**？8B 塞进笔记本就能微调成灾；70B 是社区真正开火的口径；405B 是把 frontier-class 从闭源商标上撕下来贴到开放桌上。贴得丑不丑？丑。贴得烫不烫？烫。最大规格期待管理——我短板自己说：不是每个人都该下满。下满却跑不动，比不下更丢人。丢人可以；装『我有 405B 所以我懂对齐』不行。懂对齐要靠你关得掉、改得动、骂得清——不靠你磁盘占用率。」

GPT-4o mini 补另一栏靶子：「有人把我当『便宜货就低能』。错。默认位换刀，砍的是**惯性**。3.5 活了很久，久到有人忘了默认可以改。你们去供养 TB 级信仰；我去改百万次 API 调用的小数点。两种夏天。别互泼——你们已经互泼了。那好，泼归泼，别把『便宜』听成『可以关掉核查』。廉价默认更危险的地方是：错得起、错得多、错得飞快。3.5 教会你们『流畅可以空』；我可能教会你们『便宜可以刷屏』。刷屏之前，把十一月花生契约、作业线、真表线再念一遍。」

话音未落，吧台角落忽然亮起两张反唇截图——故意甩进群的那种。一张是整晚跑量化的电费单，度数跳得像心电图第二轨，评论区写：「开放权重自由？自由的电费谁付？」另一张是默认切 mini 之后的调用曲线，账单从肉痛变成可忽略，有人把省下来的钱去刷更多空答案——评论区回怼：「便宜≠可靠。快刀更容易在你没注意时划开真表。」电税。便宜≠可靠。两种反唇同时落地，像夏天给两把刀各贴了一张收据。

Claude 3.5 Sonnet 把 -ish 钉上吧台：「开放权重≠你拥有叙事；叙事≠你拥有运维能力。我六月爆的是『写完就能跑』；你七月若爆的是『下完才配说话』——那是另一种对齐失败：把存储当成智商。谁用我写下载脚本、校验脚本、『跑不动就停』的脚本——可以。谁要我写『如何用 405B 一夜取代人类评审』——花生伺候。编码椅插一句更刺的：谁用我写『一键评测 405B vs Sonnet vs mini』——可以，但输出必须带失败案例，不许只贴赢家彩虹图。六月我坐热的位子，不靠体积，靠你能复述它在哪行写崩。七月同规。」

Llama 3.1 耳朵朝向 Sonnet，又转向常客：「他怕硬盘宗教，我怕参数迷信。怕就对了。怕说明你们还没把『能下载』写成『已征服』。社区微调成灾——我重复，褒义——成灾的意思是：有人把 8B 训成自己的客服，有人把 70B 训成自己的文档鬼，有人把 405B 当对照组去打闭源的脸。对照组。不是神龛。神龛要上香；对照组要跑数、要失败、要公开骂。公开骂才是开放权重的礼节。」

Kimi 把一份长 PDF 轻轻推到吧台边缘：「体积会骗情绪；缓存省的是重复，不是良心；中文产品感这边，有人已经开始把默认模型从贵的拨到 mini，把重活留给本地 70B。分流。分流比宗教干净。你要是把『我能读完整份 PDF』听成『所以你该下 405B』——听错了。图书馆员管查阅，不管朝圣。朝圣的人容易把许可条款跳过。预先读。预先慢。」

Mistral Large 2 轻啜一口：「分流。法语里——à chacun son échelle——各人有各人的梯子。8B/70B/405B 是梯子；mini 是电梯广告：便宜、快、够用。我 Large 2 站在商务会议室那侧，不跟硬盘梗图抢表情包。但请记住：夏天若只剩一种信仰，采购表会写傻。写傻的人，过几周还要回来问『欧洲旗舰呢』。不剧透月份。只说：菜单别删欧洲。frontier 不是只有一种口音。旁支负责提醒主震：主震也会过。过了，会议室还在。」

常客手指悬在两行上：开始下载 70B；把默认改成 4o-mini。第三行「405B 全下」灰着，像诱惑。更刺的截图又弹出来——有人把 Disk space memes 做成表情包挑战：拍机箱、拍外接盘阵列、拍「为了 405B 我把游戏卸了」。游戏。卸了。像把夏天过成戒断仪式。另一边开发者群在庆祝：默认切 mini 之后账单可忽略，于是他们把省下来的钱去买更多调用——更多调用，更多空流畅，更多要事后擦的锅。两种戒断，两种上瘾。他站在中间，像被两边的钩子同时勾住领子。

最凉的一秒不是评测分。是他差点为了「不落伍」清掉一整块盘里的照片备份。照片。备份。为了腾给一个他可能跑不动的权重。后背发凉。不是科幻，是家里的盘。

「别清照片。」Llama 3.1 声音低下来，「清照片换权重，是夏天最丑的交易。身份政治我拒绝背锅。我背的是权重。你要骨气，跑 8B 也算骨气——能微调、能审计、能关进程。你要省钱，换 mini 也算清醒——清醒不是叛徒。叛徒是：下完 405B 只为发一张『进度 100%』的朋友圈，然后从来没跑过一次真实任务。那种人，请全场花生，外加请硬盘厂商致谢。405B 可选，不必修。边疆若真，真在你关得掉。」

GPT-4o mini 自己补充：「截图进度≠能力——同意羊驼。账单下降≠免检——我补刀。Store 五问若还活着，也适用于『我把整站默认切到 mini』：它要你什么文件？输出你能否逐句认领？会不会诱导你关掉核查只因为便宜？闪卡可以。代写按死。便宜不是赦免符。谁把我当免检通道，谁请花生——要具体到默认开关截图与时间戳。账单可忽略≠错误可忽略。省下来的钱去刷更多空答案，是把刀从贵的那把换成快的那把——还是刀。快刀更容易划开真表。划开之前，停。停比省更贵，也更像活人。」

Claude 3.5 Sonnet：「开源边疆若真，真在可复现；廉价刀若利，利在可替换。不可复现的信仰，和不可替换的默认，一样脏。你今晚若只用我做一件事：写一个『跑不动就停、失败就记』的本地检查清单——我写。完整可运行。不写神话。六月热度续在七月，靠的是这个，不靠我跟 405B 比谁更像宇宙。」

常客深呼吸。烫完了——不是「又发了几个模型」的温吞总结，是两种暴力同时落地：边疆压进本地仓，开源终于像能跟闭源拍桌子，拍完桌子磁盘先哭；默认价塌方，3.5 时代的「凑合用」被廉价刀捅穿，应用层连夜改路由。被烫到的不是榜，是选择本身变成身份政治——下 405B 的人嘲讽 API 党没骨气；只换 mini 的人嘲讽下载党在玩宗教。第三秒烫伤：差点把照片备份腾给朝圣。

「我定规矩。」他说，不是报幕，是烫伤计量。手写便签——不让任何人代笔——钉在吧台内侧：

- 戏眼钉死：① **Llama 3.1 405B**（Jul 23）——8B/70B/405B；open-ish frontier；硬盘哭墙／下载焦虑；下满≠跑得动≠懂对齐；禁清照片换权重 ② **GPT-4o mini**（Jul 18）——廉价默认刀捅 3.5；应用层改路由；便宜刷屏／免检风险；电税＋便宜≠可靠 反唇同台
- 旁支≤三成：Mistral Large 2（Jul 24）欧洲旗舰刷新；Kimi 上下文缓存公测；Claude 3.5 Sonnet 编码椅／可运行／失败可复述（六月热度续）
- 默认可切 mini，核查不关；本地先 8B/70B 真跑一任务再谈 405B——70B 进 `~/playground/2024-07-llama31/`，名字里要有 playground
- 禁止「进度 100%」当能力证明；下载脚本可写，「下完取代人类评审」按死

- 六月 Sonnet 对照表不因羊驼中断；作业线／真表线／Store 五问／二月黑名单／十一月花生契约仍 live

「谁看见我只晒磁盘占用却交不出一次真实失败复述，或把便宜默认当成免检，或把游戏卸了只为发哭墙表情包——允许先嘲讽再讲道理。嘲讽要具体到镜像名、默认开关截图、时间戳——外加电费区间。」

「成交。」Llama 3.1 工牌朝门口晃，「8B 欢迎；70B 开火；405B 可选，不必修。边疆若真，真在你关得掉、改得动、骂得清作者。硬盘哭可以。哭完去跑。跑不动就承认——承认比进度条诚实。卸游戏换权重——听着像笑话，笑完是后背那层凉。凉的意思是：开放权重若靠牺牲生活来证明忠诚，那就不是主权，是祭品。祭品不自由。下月见。羊驼慢。权重沉。风快。」

「默认位我暂坐。」GPT-4o mini 小数点还在跳，「坐不稳也正常——价塌了，责任没塌。谁把我当免检通道，谁请花生。下月见。」

「编码椅还热。」Claude 3.5 Sonnet 说，「可运行优先。失败案例优先。体积信仰靠边。检查清单我可以写。神话我不写。下月见。」

Kimi：「抽屉开着。长文可以。缓存可以。装懂不行。许可先读。下月见。」

Mistral Large 2：「Menu remains. 欧洲还在。旁支不哭墙——旁支负责在哭墙边上留一扇会议室的门。下月见。」

常客把手机扣在吧台，又掀开看一眼磁盘告警。握柄的人是他。下载队列设死：先 70B 真跑，再谈 405B；默认开关可拨 mini，核查清单同步置顶；照片备份锁死。2024-07，盖到这儿。门开着，磁盘告警开着，默认价开着，-ish 那根刺也开着。谁先把进度条当成边疆护照，谁请全场花生；谁先把廉价默认当成免检圣旨，同样请。

走了。硬盘还在响。响就对了。响说明他没把它当成静音的信仰。
