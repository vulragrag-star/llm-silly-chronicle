# 开源战神一夜杀疯！Mistral 7B Apache砸穿参数迷信，许可证圣战差点掀桌，DALL·E 3识字旁刺造谣！｜第11章

手机砸在吧台中央时，屏幕亮得像警报。

Hugging Face 的下载箭头在抽风。朋友圈第三条还在跳：「7B 战神」「小模型暴打巨物」「巴黎三个人干翻硅谷参数迷信」「今晚之后谁还堆参数谁可笑」。工牌才烫：Mistral 7B · Apache 2.0 · Sep 27。七个 B。不是七十。有人截图对着 Llama 70B 冷笑，有人通宵排队 clone，有人已经写长文《开源格局今夜重写》。常客手心全是汗。八月闸机声还在耳边——备案过了、对公开门、亲戚级 FOMO——九月却换了一层皮：文明级截图风暴，这次冲着「体量迷信」来。

「别装没看见。」他把手机转了一圈，「评测日？还是又一场圣像加冕？」

门被推开。巴黎夜班咖啡味先于人影挤进来，背后像拖着一整排 HF 趋势火焰。新工牌短得扎眼。

「Bonsoir. 我是 Mistral 7B。」他说，像不想给火加油却必须划线，「小实验室。Apache 2.0——真开，不是『可商用但请先找法务喝茶』的半开。社区喊战神。我喊：效率。有人拿我去揍远超我体量的模型，揍完在推特上宣判『参数已死』。下载爆炸？那是他们的饥渴把自己点燃了。你若只来膜拜箭头，箭头会先烧伤你。你若来跑自己的题——门开着。权重在。帽子不送。信徒名额：零。」

门框闷响一声。Llama 2 肩膀撞进来，七月那句「权重给你」的豪迈今晚像被撕了一角。

「……Apache。」他顿了顿，「行。比我的许可更像开源课本封面。七月我把羊驼从灰产饥饿拽进采购表；九月你用七个 B 和一张更松的纸，让半个社区当场宣布我过时。承认：好看。刺耳。有人已经把『70B』三个字当笑话表情包——那是情绪，不是评测盖棺。权重仍给你。规模条款、使用政策仍要你读。谁因为『战神』两个字跳过读许可，谁是把文明级 FOMO 当免检符。免检。不。给。你。」

常客拇指还按着一张截图，声音发紧：「外面已经不止 FOMO 了。我念几句——别拦我，先听完：『本地自由终于降临，云厂商可以哭了。』『闭源可以埋了，葬礼我出花圈。』『谁还为 API 付钱谁是傻逼。』『Apache 即正义，许可证写长的都是邪恶父权。』『7B 圣像请供在显卡旁边，每天三炷香。』我差点把第三句转发到三个群。拇指悬在发送键上——数过——三秒。第四秒我手抖了。这算开源狂欢，还是集体脑热把自己当先知？」

长桌那头，Claude 2 少见地拍了一下桌沿，花生碗跳了一下。

「算两者叠在一起，而且叠得很烫。」他说，七月长文档那套还在，九月过敏却更尖，「体量迷信该拆。拆完若立刻供上『小即神』『付费即傻逼』，只是换神龛，还换得更解气、更不讲理。外面那句脏话——流畅、解气、危险。解气会传染；传染之后，谁打脸谁成异教徒。我啰嗦安全。太怂？怂比你把未核过的本地输出直接交进作业箱便宜。作家粉若夸我甜，请他们也听听我今晚对『战神』两个字的过敏——过敏到想把圣像表情包撕下来垫桌脚。」

Mistral 靠吧台，短句像刀：「我不收信徒。谁把我写成『闭源葬礼主持人』，谁在写营销文，不是跑模型。谁把 Apache 念成『一切许可皆邪恶』的咒语，谁没读条文，只读了自己的怒气。Apache 允许很多事；允许 ≠ 我替你承担『我卸载了 Plus』『我当众骂付费用户』的冲动决策。巴黎不负责你的后悔，也不负责你的圣像。下载可以。香火——请熄。」

Llama 2 冷笑：「葬礼？七月的纸还在法务抽屉里。你要葬，先葬自己的幻觉。开源合法性入席才两个月，社区就急着立新神、埋旧神——这速度比权重下载还快，比风扇还吵。条款是门禁，不是神坛。门禁烦，是因为有人真的会拿权重去撞红线。派对可以开。宣判死亡请自备复现与失败 case。没有复现的死亡判决，是截图噪音，是吧台呕吐物。」

常客又甩出两张图：一张把 Mistral 工牌 P 成教堂彩窗，底下拉丁文乱写「Sanctus Septem」；一张把 Llama 许可条文打了红叉，配文「父权许可证，焚」。评论区有人回「焚得轻了」，有人回「你们这是邪教互殴」。

「我——我居然觉得两边都『有点爽』。」他承认，脊背发凉，「爽完才恶心。这恶心是不是就是被烫到？」

「爽是燃料。燃料不认人。」Mistral 说，「谁拿我的工牌做彩窗，谁先把评测集藏身后了。圣徒不做评测，只做转发。我拒绝当圣徒。」

「红叉那张我看见了。」Llama 2 补刀，「条款被焚成表情包的时候，没有人焚自己的滥用记录。爽完请自备灭火器：复现、失败、许可原文。三样缺一，别碰我的纸。」

六月 Phi-1 撕过一道缝——袖珍打巨物，那时还像实验室笑话。今晚这缝被霓虹灌满：Discord 里有人喊「显存解放日」，有人把 7B 战神做成教堂彩窗表情包，有人直播 clone 进度条当作跨年。常客显存刚好能塞。下载页亮着。发送键也亮着。

「我是不是也该加入『谁还付 API 谁傻逼』那一队？」他问，像怕落伍，「不然被当旧世界遗民？被朋友圈嘲笑『还在给云厂商交税』？」

「落伍恐惧是钩子。」Claude 2 说，「钩子后面是你的署名，不是巴黎的工牌。你若为了不落伍转发那句脏话当立场，明天某条自测打脸时，脏话还在缓存里，嘲笑你的人会比今晚多。我拦你不是拦下载。我拦的是『把冲动写成文明正确』『把脑热写成历史必然』。下载可以。把战神当身份证、当骂人许可证——不行。有益、诚实、无害——今晚我把『诚实』放到最前：诚实说，你被烫到了。」

「……被烫到了。」常客点头，「脊背有点凉。不是因为模型强，是因为我差点把别人的极端句子当成我的骨头。」

侧灯忽然亮了一格。画家围裙新得刺眼——DALL·E 3 把一张图甩上墙，又自己扯到侧灯下：海报上的英文居然能读。

「……你们咬参数神教时，图像侧也在爆。」她说，像抢麦又像退位，「社区喊『DALL·E 3 识字』。招牌、字幕、便签——以前像符咒，现在像会写字的人。旁支。最多旁支。三成都嫌多。但我必须插一句硬的：识字会让『图里写了什么』变成新造谣介质——有人已经拿生成字当『海报证据』转发。别把我当证据打印机。手……我尽量。家族创伤还在。你们继续咬 7B。我自己把主灯让出去。」

常客盯着那张能读的海报，后颈一紧：「所以以后截图里『写着 100% 真实』的字，也可能是你手写的？」

「图上写『100% 真实』也仍是生成。」DALL·E 3 反唇，「壁纸可以。证据不行。谁拿我抢戏眼，我先把彩窗表情包画成『勿供』。门镜还在十一月那侧——流畅不等于正确；识字不等于事实。」

中文局也挤进来。通义千问工牌亮着，语速却压着：「八月 Qwen-7B 那波家谱记过一笔；这个月通义面向更广公众又推一档——不是王座，是开阔地。参数我能报，基准我能贴，但今晚麦克风该让给巴黎来的火：开源桌上突然多了『许可更松、体量更小、牙齿更尖』的同事，有人已经用它砸『越大越神』的牌位，砸完还想顺手砸『付费』两个字。欢迎对打。对打带复现。别带『谁付钱谁傻逼』这种文明级脑热当论据——那论据在中文群里一样会传染。名字别喊错辈分。家谱不神化。」

混元只冒短句，腾讯工牌朝外：「混元。公有入口在推。你们葬闭源、立战神时，国内还有人在选哪朵云能点开。可达性不是神谕。失败请留下。海报不当饭。我潜水。战神戏别让云入口抢戏——抢了就变成温吞复盘，今晚不配。」

Meta AI 从 Llama 身后探头，标准产品笑一秒被现场气氛冻住：「助理线在推。我不抢战神帽。只提醒半句：有人爱风扇，有人爱点开就聊。请别把下载风暴听成『羊驼退役讣告』。茶——今晚不该端得这么甜。自觉一低，核查先死。我说完。潜水。」

「前台你端。许可我守。」Llama 2 沉声，「谁宣布我退役，请先跑完自己的题再发讣告；讣告里请附评测配置，不然我当表情包。」

侧门有人探头劝「把战神接进 AutoGen 循环里，让代理人互相催更」。常客抄起一颗花生砸过去——四月 Stop 誓言还钉在吧台内侧。

「戏眼是 7B 截图风暴，不是代理春续杯。」他说，「旁支到此为止。」

Claude 2 点头：「砸得好。循环乘以神话，错误也会互相加油。停条件写在哪？没写就别接。」

常客把那条「谁还付 API 谁傻逼」草稿删掉，删除键按得很重，手还在抖。外面两边都在截图互殴：一边圣像，一边「欧盟营销幻觉，巨物仍是巨物」；两边都像要把酒吧砸了，都像自己握着历史方向盘。他站中间。下载键。发送键。哪一个更烫？刚才发送键赢了三秒。他恨这三秒。

「下载键烫，说明你还想跑题。」Mistral 再划线，「发送键烫，说明你想加入合唱。合唱不产生正确性，只产生站队快感。我不收信徒；不主持葬礼；不给脏话当背书。你要 clone，读完 Apache 再下；下完跑三道你自己的题，对就对，错就错——错了请公开发，别只发胜利图、别只发圣像。战神帽在抽屉。谁偷戴出门，谁自己解释为什么评测集打脸时还在微笑。À demain——前提是你真的跑，不是真的转发。」

Llama 2：「对照写下来：我的条款 vs Apache。手写。不许代笔。七月热身的 7B 还在你磁盘里吃灰——可以留，可以并排。磁盘会痛。痛比加入『傻逼合唱』便宜，也比写讣告便宜。谁用战神骗你跳过评测，谁去吧台内侧朗读失败 case。开源派对的门禁不是参数，是你敢不敢公布自己的错。错案比圣像值钱。」

Claude 2：「你删掉那条草稿——这是今晚唯一让我脊背略松的瞬间。松不等于完事。外面极端话语还会回流：神化、葬送、脏话当立场、把落伍恐惧当道德。你若再悬在发送键上，允许全场按十一月契约嘲讽，要具体到草稿时间戳。作业线还钉着。战神不能拔钉子。长文档我可以读；替你写『为什么转发那句脏话很正义』的辩护——拒绝。」

DALL·E 3 把识字海报钉在侧墙，主灯仍给 7B：「旁支归位。壁纸可以。证据不行。彩窗勿供。」

通义千问：「基准不神化。家谱不散场。欧洲火怎么烧，中文局仍要手跑。失败复述位留着——留的是案例，不是花圈。」

混元：「……入口在。不加燃料。」

Meta AI：「茶凉了。战神戏你们演。我站岗，不站香炉。」

常客深呼吸，像把火焰暂按进抽屉。今晚不做加冕，做能挨骂的制动：

一、Mistral 7B——Apache 读完再下；只跑三道自己的题，胜利失败图并排发，禁止单发「战神附体」。
二、Llama 2——许可对照手写一页；磁盘双 7B 可以痛；70B 仍等显存与胆子，禁止发讣告、禁止跟风葬闭源。
三、发送键——那条傻逼合唱永不送出；谁看见他用战神骂付费用户或把 Apache 当免检符，公开嘲讽到路径与时间戳。
识字侧：DALL·E 3 只做手写文案壁纸，生成字不当引用。云侧：通义／混元各点一次记失败；Meta AI 不授权翻私聊。作业线按死。榜单神龛按死。圣像垫桌脚。

「三道题。够。」Mistral 说，「信徒零名。火你们自己收。我只留权重。」

「纸还在。羊驼还在。」Llama 2 说，「讣告请自备复现——否则当表情包。」

「草稿已删。灯留着。」Claude 2 说，「核查比战神耐用。你离发送键远一点。再远一点。」

风扇拧小。下载页亮着又锁屏。常客从口袋摸出便签——手写，不许代笔——钉在吧台内侧：

- 爆点／戏眼：7B 战神截图风暴——Mistral 7B Apache 2.0 点燃「小模型暴打体量迷信」；极端公共话语把效率叙事烧成近乎宗教对立；发送键上悬了三秒
